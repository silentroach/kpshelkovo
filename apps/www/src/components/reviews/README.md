# Компоненты отзывов

- `ReviewMeta` по умолчанию выводит дату, подпись автора и часть посёлка. `authorFirst` меняет именно DOM-порядок на подпись → дата → часть посёлка; список включает его, шапка отдельного отзыва сохраняет default. `showVerified` независимо добавляет существующую отметку проверки; без подписи используется «Анонимный собственник».
- `ReviewCard` показывает заголовок-ссылку, метаданные, необязательный `Review.excerpt` и только оценённые темы в предметном порядке. Фрагмент проходит `formatText` и обычное экранирование Astro; это текст, не Markdown и не HTML. `blockquote[cite]` ссылается на тот же полный отзыв, что заголовок. Без фрагмента нет автоматического fallback или пустого блока.
- Компактный рейтинг задаётся только внутри карточки через `--star-rating-size`, `--star-rating-gap` и `--star-rating-fill`. [Контракт примитива](/packages/ui/README.md) сохраняет прежние defaults для `ReviewAspectList`. В узком контейнере темы становятся строками; подписи, имена и фрагмент могут переноситься без обрезки.

Параметры композиции — в [дизайн-гайде](/docs/design/design-code-shelkovo.md#карточка-отзыва).
