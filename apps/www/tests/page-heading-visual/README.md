# Визуальный стенд PageHeading

Изолированный холст с настоящими шрифтами, фоном и foundation сайта, без меню. Не входит в production-маршруты.

- Запуск: `pnpm --dir apps/www test:visual:page-heading`.
- Обновление эталонов: `pnpm --dir apps/www test:visual:page-heading:update`.
- Отдельный preview: `pnpm --dir apps/www test:visual:page-heading:serve`, адрес `http://127.0.0.1:4336`.

Снимки охватывают ширины 320, 390, 768, 1024 и 1440 px, а также 320 и 390 px с размером текста 200%. Проверяются короткое название, длинное слово, многострочный заголовок, диапазон дат, 0–3 действия, отсутствие пояснения и несколько абзацев со ссылкой. Тесты дополнительно проверяют горизонтальное переполнение.

В слоте действий используются `HeadingActionWebsite`, `HeadingActionTelegram` и `HeadingActionMap`. Обёртки задают иконки, подписи и параметры переходов; страница передаёт только адреса.

Эталоны зависят от ОС и Chromium. Обновляй их после просмотра изображений; успешное создание снимков само по себе не подтверждает правильность композиции.
