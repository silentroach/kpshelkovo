# Проба открытия меню

Изолированный стенд с настоящими `SiteHeader` и `SiteNav`, текущими шрифтами и стилями сайта. Сам стенд не добавляет публичный маршрут и не управляет поведением production-меню. Статус сервисов задан пустым набором инцидентов через локальный alias; карта использует существующий SVG-фон визуальных тестов без SDK и внешних запросов.

Запуск из корня workspace:

```bash
pnpm --dir apps/www exec node ../../scripts/visual-fixture-launcher.mjs tests/site-menu-motion-visual 14336
```

Адрес: http://127.0.0.1:14336/ . Команда собирает стенд и запускает Astro preview, как у существующих визуальных тестов. Перед повторным запуском остановить текущий сервер.

- Переключать эффект и фон; для desktop раскрывать «Тариф 815», для mobile «Меню».
- Сравнивать мгновенное закрытие и переход 150 мс; движение панели составляет 4 px.
- Проверять уменьшенное движение через чекбокс или системную настройку.
- Ссылки закрывают панель, но не уводят со стенда. Поиск отключён. Реальные клиентские переходы и взаимодействие с картой проверяются после выбора эффекта на сайте.
- Плавное закрытие мобильного `details` зависит от поддержки `::details-content`; в старых браузерах возможен мгновенный показ/скрытие. Это ограничение пробы, не согласованный production fallback.
