# Демо карточки места для #756

Локальный макет для визуального обсуждения. Две страницы используют текущие данные мест,
шрифты, типографику, маркеры и компонент расписания сайта.

- `/` — Охотничьи пруды: текст, оба контура водоёмов и соседние места.
- `/burzhuyka/` — Буржуйка: описание, адрес, расписание, контакты и карта.
- Превью использует существующий runtime Яндекс Карт с отключёнными жестами.
- Соседи: до трёх мест с `show_on_map: true` в радиусе 1 км по прямой между точками.
- Ссылки на карты, контакты и соседние места ведут на настоящие страницы.

Выбранный вид: правая колонка начинается на уровне хлебных крошек; расписание
стоит перед описанием, адрес подписывает карту. Кнопки общей карты и контактов
расположены у заголовка. В списке соседей нет разделителей и видимых подписей
состояния; состояние остаётся доступным скринридеру.

План основной реализации: [redesign-place-card](../../../../openspec/changes/redesign-place-card/proposal.md).
Сравнение с production: [скриншоты](../../../../openspec/changes/redesign-place-card/preview/README.md).

Запуск из корня workspace:

```bash
pnpm --filter @shelkovo/www exec node ../../scripts/visual-fixture-launcher.mjs tests/place-card-demo 4336
```

Открыть <http://localhost:4336/>. Ключ карты загружается из корневого `.env`,
как в основном приложении. После правок перезапустить команду: демо собирается статически.
