# site-analytics Specification

## Purpose

Управляет подключением Яндекс Метрики к статическому сайту, позволяя отключить аналитику при сборке и вернуть её без изменения интеграции.

## Requirements

### Requirement: Переключатель аналитики действует только при сборке

Система MUST определять подключение Метрики по версионируемой конфигурации на этапе сборки. Клиентский runtime MUST NOT читать этот флаг из конфигурации или запрашивать его по сети. Изменение флага MUST требовать новой сборки и публикации для изменения поведения сайта.

#### Scenario: Изменение конфигурации без новой публикации

- **WHEN** флаг в исходном конфиге изменён, но новая сборка не опубликована
- **THEN** ранее опубликованные страницы сохраняют прежнее поведение аналитики

### Requirement: Отключение охватывает все способы отправки аналитики

При выключенной Метрике система MUST выпускать страницы без маркера подключения счётчика и `noscript`-пикселя. Эти страницы MUST NOT загружать скрипт Метрики или отправлять ей просмотры и цели, в том числе при клиентской навигации.

#### Scenario: Посещение с JavaScript

- **WHEN** посетитель открывает страницу из сборки с выключенной Метрикой и переходит на другую страницу
- **THEN** сайт не загружает Метрику и не отправляет ей просмотры или цели

#### Scenario: Посещение без JavaScript

- **WHEN** посетитель без JavaScript открывает страницу из сборки с выключенной Метрикой
- **THEN** страница не содержит пиксель отправки просмотра Метрике

### Requirement: Включение сохраняет ограничения окружения

Система MUST подключать Метрику только в production-сборке при включённом конфиге и отсутствии принудительного отключения через `LIGHTHOUSE_DISABLE_ANALYTICS=true`. Включённая интеграция MUST сохранять учёт клиентских переходов и существующих целей.

#### Scenario: Повторное включение

- **WHEN** опубликована production-сборка с включённым конфигом без принудительного отключения
- **THEN** страницы подключают счётчик, пиксель без JavaScript и существующий учёт переходов и целей

#### Scenario: Принудительное отключение для аудита

- **WHEN** production-сборка выполняется с `LIGHTHOUSE_DISABLE_ANALYTICS=true` при включённом конфиге
- **THEN** Метрика остаётся отключённой

#### Scenario: Разработка

- **WHEN** сайт работает в режиме разработки при включённом конфиге
- **THEN** Метрика остаётся отключённой
