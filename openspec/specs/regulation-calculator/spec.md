# regulation-calculator Specification

## Purpose

Давать читателю доступное управление включением позиций сметы в калькуляторе регламента, сохраняя связь переключателя с видимым названием строки и её расчётом.

## Requirements

### Requirement: Переключатель позиции называется по видимому заголовку

На `/815/regulation/` каждый переключатель включения позиции SHALL быть нативным HTML-чекбоксом с доступным именем, совпадающим с видимым названием соответствующей строки без общего префикса. Название строки SHALL NOT повторяться в доступном описании чекбокса. Видимое название SHALL сохраняться как заголовок строки. Имя и начальное состояние SHALL быть доступны без JavaScript.

#### Scenario: Определение позиции по имени

- **WHEN** пользователь обращается к чекбоксу позиции через средства доступности
- **THEN** его имя совпадает с видимым заголовком строки без общего префикса
- **AND** название не повторяется в доступном описании

#### Scenario: Серверная разметка без JavaScript

- **WHEN** пользователь открывает страницу с отключённым JavaScript
- **THEN** чекбокс имеет имя по видимому заголовку строки и начальное состояние согласно исходной смете

### Requirement: Переключатель сохраняет нативное управление и участие в расчёте

Чекбокс позиции SHALL сохранять последовательную навигацию Tab и нативное переключение клавишей Space. При работающем JavaScript переключение SHALL включать позицию в расчёт тарифа или исключать её согласно состоянию чекбокса, сохраняя доступное имя и заголовок строки.

#### Scenario: Клавиатурное управление

- **WHEN** пользователь с работающим или отключённым JavaScript переводит фокус на чекбокс клавишей Tab и нажимает Space
- **THEN** нативное состояние чекбокса переключается, а заголовок и доступное имя сохраняются

#### Scenario: Пересчёт позиции

- **WHEN** пользователь переключает чекбокс при работающем JavaScript
- **THEN** позиция включается в расчёт или исключается согласно состоянию чекбокса без изменения его доступного имени
