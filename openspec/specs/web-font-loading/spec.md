# web-font-loading Specification

## Purpose

Посетитель получает читаемый текст при медленной или неуспешной загрузке шрифтов. Доставка шрифтов сохраняет типографику сайта и ограничивает сетевую стоимость нужными странице начертаниями и алфавитами.

## Requirements

### Requirement: Доставка шрифтов с origin страницы

Основной сайт и самостоятельная media 404 SHALL доставлять веб-шрифты с origin открытой страницы. Получение текста и шрифтов браузером MUST NOT требовать обращения к внешнему шрифтовому сервису.

#### Scenario: Посещение основного сайта

- **WHEN** посетитель открывает страницу основного сайта с пустым кешем шрифтов
- **THEN** все сетевые запросы, необходимые для подключения её веб-шрифтов, направлены на origin основного сайта

#### Scenario: Самостоятельная media 404

- **WHEN** посетитель открывает страницу отсутствующего файла на media-origin
- **THEN** её веб-шрифты доставляются с media-origin без запросов шрифтов к основному сайту или стороннему сервису

### Requirement: Загрузка в пределах Font Budget

Страницы SHALL использовать семейства, начертания, формат файлов и предел базовой загрузки из [Font Budget](/docs/design/design-code-shelkovo.md#font-budget). Дополнительные наборы символов SHALL загружаться только для текста, которому они нужны. Страницы MUST NOT предзагружать веб-шрифты через preload.

#### Scenario: Подключение без font preload

- **WHEN** посетитель открывает страницу основного сайта или самостоятельную media 404
- **THEN** её HTML не содержит font preload, а нужные тексту веб-шрифты загружаются через CSS

#### Scenario: Текст в пределах базовых алфавитов

- **WHEN** видимый текст страницы использует только символы базовых Latin и Cyrillic
- **THEN** шрифтовые запросы укладываются в базовый бюджет и не включают `latin-ext`

#### Scenario: Расширенная латиница в тексте

- **WHEN** основной сайт отображает символы из `latin-ext`, которых нет в базовых наборах, и соответствующий файл ещё не закеширован
- **THEN** браузер загружает соответствующий набор нужного начертания без предварительной загрузки остальных расширенных наборов

#### Scenario: Облегчённая самостоятельная страница

- **WHEN** самостоятельная media 404 использует только часть начертаний и алфавитов общего Font Budget
- **THEN** она загружает только нужную ей часть и не предзагружает остальные файлы ради общего подключения

### Requirement: Читаемый текст во время загрузки шрифтов

Страницы SHALL показывать текст системным fallback, пока веб-шрифт загружается, и сохранять читаемость при ошибке его загрузки. Fallback основного сайта SHALL быть подобран по метрикам целевого начертания там, где соответствующий системный шрифт доступен. Самостоятельная media 404 SHALL использовать системные fallback без коррекции метрик. Применение fallback MUST NOT обрезать текст или перекрывать элементы управления. После загрузки веб-шрифтов SHALL применяться типографические роли дизайн-гайда.

#### Scenario: Медленная загрузка

- **WHEN** HTML и стили страницы доступны, а ответ с веб-шрифтом задерживается
- **THEN** заголовки, основной текст и подписи элементов управления отображаются доступным системным fallback до завершения загрузки файла

#### Scenario: Ошибка загрузки

- **WHEN** запрос веб-шрифта завершается ошибкой
- **THEN** текст остаётся читаемым, подписи элементов управления не обрезаны, а ссылки и кнопки доступны для использования

#### Scenario: Успешная загрузка

- **WHEN** нужные странице веб-шрифты успешно загружены
- **THEN** заголовки и основной текст отображаются соответствующими семействами и начертаниями из дизайн-гайда
