# Proposal

## Why

После включения «Клубных мест» дальняя точка может остаться за пределами текущего кадра. Карта должна показывать весь видимый состав после ручного включения такого слоя.

Это уточнение [#1212](https://github.com/silentroach/kpshelkovo/issues/1212) в открытом [PR #1215](https://github.com/silentroach/kpshelkovo/pull/1215); исходный слой уже описан в [архиве](/openspec/changes/archive/2026-11-03-add-club-places-layer/proposal.md).

## What Changes

- Добавить слою необязательное свойство `fit`; отсутствие поля и `false` не вызывают вписывание.
- Для `club` задать `fit: true`; у инфраструктуры и участков свойство не задавать.
- При ручном включении слоя с `fit: true` вписывать все видимые объекты карты с запасом для маркеров и управления.
- При выключении сохранять текущий кадр. Начальное включение через `l`, прямой фокус `h`/`p` и наборы не запускать через ручной fit; активная прямая цель или набор сохраняют приоритет камеры.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `place-map-visibility`: вписывание по настройке слоя при ручном включении вместо безусловного сохранения кадра клубного слоя.

## Impact

- Конфигурация слоёв, обработчик переключения и вычисление кадра общей карты; связанные компонентные тесты и дизайн-гайд.
- Форматы карточек, `/map/data/places.json` и URL не меняются: `fit` относится к настройке слоя, не к отдельному месту.
- Новых зависимостей, запросов и обязательного движения нет; используется существующий расчёт кадра, переход без анимации.
- Результат входит в PR #1215. Отдельная production-приёмка не нужна; мобильный режим с корневым шрифтом 200% остаётся вне объёма по прежнему решению владельца.
