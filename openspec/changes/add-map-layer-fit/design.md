# Design

## Context

Обоснование находится в [proposal.md](/openspec/changes/add-map-layer-fit/proposal.md). В `PlaceMap.svelte` ручное управление уже отделено от начального `l` и автоматического включения для `h` и набора. Поэтому новый эффект достаточно запускать из ручного обработчика, не меняя загрузчики и URL.

`fitPlaces()` использует начальный кадр по умолчанию и не подходит для новой задачи: он исключает дополнительные слои. `getSelectionSetBounds()` уже объединяет контуры участков, геометрию мест и точки; его можно использовать для вычисления текущего видимого состава.

Решение продолжает [ADR-028](/docs/decisions/028-markdown-first-places-map.md) и [ADR-039](/docs/decisions/039-shared-yandex-maps-runtime-and-preview.md). Новый ADR не требуется.

## Goals / Non-Goals

**Goals:**

- Необязательная настройка слоя `readonly fit?: boolean`, а не проверка идентификатора `club` в обработчике.
- Однократное вписывание текущей видимой сцены после ручного включения.

**Non-Goals:**

- Новый параметр URL или поле каждого места в публичном JSON.
- Постоянное слежение за кадром, отложенные перефиты после загрузки частей или возврат к предыдущему масштабу при выключении.
- Автоматическое вписывание инфраструктуры и частей участков, новая анимация либо расширение на режим root font 200%.

## Decisions

- В небольшом app-owned конфиге слоёв задать `club: { fit: true }`. Тип настройки вынести в отдельный types-модуль. Типизированная карта допускает отсутствие настройки для остальных слоёв; проверять только истинное значение `fit`. Не нормализовать отсутствие к обязательному `false` и не добавлять `fit` в DTO места.
- После применения ручного включения и синхронизации маркеров вычислить кадр из всех видимых маркеров мест, уже загруженных и показанных участков и только раскрытой дополнительной геометрии. Не раскрывать геометрию ради fit и не ждать новые запросы участков. Скрытые/неподготовленные объекты не участвуют.
- Не запускать fit, если слой не добавил видимых мест, если событие не меняет выключенный слой на включённый либо если камера принадлежит действующей подсветке `h`, выбранному/ожидаемому участку или активному/ожидаемому набору.
- Обновить карту один раз с рассчитанными bounds, существующим margin и `duration: 0`. Это укладывается в пожелание пользователя без необязательной анимации, таймеров и новых правил её прерывания.
- Не переиспользовать `fitPlaces()`: начальное открытие и resize должны сохранить свои правила. Альтернатива с прямым `if (layer === 'club')` отклонена, потому что владелец выбрал свойство слоя.

## Risks / Trade-offs

- Поздняя загрузка части участков может добавить контуры вне уже рассчитанного кадра. Fit учитывает только показанные объекты на момент ручного действия; повторного автоматического изменения не будет.
- После нового fit обычный resize не должен возвращать начальный локальный кадр. Сохранить выбранный кадр в том же смысле, что ручное перемещение; проверить resize отдельно.
- Активный набор сохраняет приоритет, поэтому включение слоя при наборе не обязано показать дальние точки. Это соответствует согласованному приоритету прямых ссылок.
