# Spec Delta

## ADDED Requirements

### Requirement: Поиск инвентаря ведёт к видам с предложениями

Внутрисайтовый поиск SHALL включать страницы видов `/ukogo/<group>/<kind>/` только при наличии предложений. Поисковый текст SHALL включать название вида, его редакционный body, названия с моделями и описания действующих предложений. Главная каталога и страницы групп SHALL не входить в выдачу как дублирующие оглавления.

#### Scenario: Поиск конкретной модели

- **WHEN** модель названа в опубликованном предложении вида
- **THEN** страница этого вида доступна в поиске по модели с контекстом из предложения

#### Scenario: Последнее предложение снято

- **WHEN** на очередной сборке у вида нет предложений, но сохранился редакционный body
- **THEN** страница исключена из внутрисайтового поиска, оставаясь доступной по прямым и редакционным ссылкам

#### Scenario: Предложение появилось снова

- **WHEN** на очередной сборке у ранее пустого вида есть предложение
- **THEN** страница снова включена во внутрисайтовый поиск с актуальным содержанием

### Requirement: Внешняя индексация инвентаря сохраняет постоянные страницы

HTML каталога `/ukogo/`, групп и видов SHALL разрешать внешнюю индексацию, иметь собственный canonical и входить в sitemap независимо от наличия предложений. Прямые и negotiated Markdown companions SHALL следовать `public-markdown-delivery`, включая `noindex, follow`.

#### Scenario: Вид временно не содержит предложений

- **WHEN** последняя запись предложения снята, а страница вида сохраняется
- **THEN** её HTML остаётся в sitemap, сохраняет canonical и разрешённую внешнюю индексацию независимо от исключения из внутрисайтового поиска

#### Scenario: Публикация оглавлений

- **WHEN** опубликованы главная каталога и страница группы
- **THEN** их HTML включён в sitemap и открыт для внешней индексации, а Markdown-копии получают `noindex, follow`
