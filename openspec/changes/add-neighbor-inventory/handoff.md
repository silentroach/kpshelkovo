- `https://media.kpshelkovo.online/ukogo/worx-wx530/product.jpeg` неоднократно завершался TCP timeout (status 000); системный и публичный DNS указывали `80.93.63.117`. Последний независимый GET тоже не установил соединение за 10 секунд. URL **не добавлен** в данные предложения.
- Для продолжения использовать `public-media-publisher` и [runbook](/ops/storage/public-media.md). Подключить существующий объект только после успешной проверки canonical media-origin: статус, MIME, размер, SHA-256, размеры и метаданные. Прямой S3-host не подменяет эту проверку; занятый key не перезаписывать. У фото указать фактические размеры, alt и подпись о фото модели.
