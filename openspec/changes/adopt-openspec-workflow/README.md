# adopt-openspec-workflow

Настроить единый процесс разработки и воспроизводимую интеграцию OpenSpec.

- Постановка: [#736](https://github.com/silentroach/kpshelkovo/issues/736).
- Рамка и этапы перехода: [#734](https://github.com/silentroach/kpshelkovo/issues/734).
- Рабочая ветка: `chore/736-openspec-workflow` в текущей рабочей копии.
- Статус: реализация разрешена владельцем 14 сентября 2026 года сообщением «разрешаю» после представления change.
- Граница от владельца: глобальные skills и их lock-файлы не менять.

Для согласования прочитать [предложение](proposal.md), [технический подход](design.md), [правила процесса](specs/development-workflow/spec.md), [требования к установке](specs/agent-tooling/spec.md) и [задачи](tasks.md).

Для подготовки change установлен `@fission-ai/openspec@1.13.0` и выполнена штатная инициализация OpenCode. Прогресс реализации отмечается в `tasks.md`. Разрешение относится к реализации в текущей рабочей копии; коммит и PR пока не опубликованы.
