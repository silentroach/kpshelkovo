## Выполненные проверки

- Frozen-установка зависимостей прошла с закреплёнными `@fission-ai/openspec@1.13.0` и `skills@1.5.24`.
- `pnpm skills:install` восстановил 44 внешних skills из 12 Git-источников, сверил исходные хеши и применил patch. Четыре собственных skills остаются в Git.
- `pnpm skills:check` прошёл после штатной переустановки: обратное снятие patch и хеши подтверждают воспроизводимость адаптаций.
- `pnpm openspec:generate` / `pnpm openspec:check`: 14 файлов совпали со штатным генератором.
- `pnpm openspec:validate`: change прошёл строгую валидацию.
- Явный запуск oxfmt по всем generated skills/commands обработал 0 файлов; последующая сверка генерации прошла. Это тот же formatter и способ передачи путей, который использует lint-staged.
- Два теста tooling прошли: независимость генерации от профиля и обнаружение drift; неполная установка skills, несовместимый patch и обратная проверка исходного содержимого.
- `pnpm typecheck` прошёл: три workspace-задачи, ошибок нет.
- `pnpm test` прошёл: шесть workspace-задач; в основном приложении 189 файлов и 1207 тестов прошли. Ожидаемые сообщения об отсутствии Yandex Maps API относятся к тестам fallback-сценариев.
- `actionlint 1.7.12` проверил `.github/workflows/agent-tooling.yml` без замечаний. Для проверки использован временный бинарник, SHA-256 сверён с официальным release manifest.
- В чистой временной копии предполагаемого коммита, полученной из локального Git clone с текущим diff, `pnpm agents:setup` выполнен дважды. Домашний каталог и XDG-каталоги были изолированы, прежнего `node_modules` и ignored skills не было. Оба запуска прошли; Git diff после восстановления пуст.
- В той же копии прошли `skills:check`, `openspec:validate` и оба теста tooling. Новый процесс `opencode debug skill` загрузил 56 уникальных skills: 44 внешних, четыре собственных, семь OpenSpec и один встроенный. Удалённые методы отсутствуют; `domain-modeling` загрузил адаптацию с `GLOSSARY.md`.
- Проверка вывода OpenCode сначала упёрлась в обрезание большого JSON при выводе в pipe. Повторный запуск с выводом в обычный временный файл дал полный JSON; данные проверены Zod. Это не ошибка bootstrap.
