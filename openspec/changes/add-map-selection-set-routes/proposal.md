# Proposal

## Why

Участники Хеллоуина должны видеть порядок посещения домов и путь к общему финалу по существующей ссылке на набор. Сейчас набор подсвечивает участки, но не может содержать собственные линии и нумерованные остановки.

## What Changes

- Дополнить именованные наборы необязательной редакционной геометрией, используя существующий GeoJSON-контракт и renderer карт.
- Показывать геометрию вместе с открытым набором, учитывать её при начальном вписывании и удалять действием «Снять набор».
- Расширить цифровые метки редакционных точек до двузначных номеров, сохранив обычные маркеры и подписи.
- Сохранять геометрию набора в его публичных данных и при использовании набора во встроенной Markdown-карте.
- Добавить в `2026-halloween` сохранённый автомобильный путь и точки 1–18 у домов, точку 19 у лесного парка Фореста. Состав участников и порядок берутся из обсуждения; M48 исключён.
- Оставить расчёт маршрута редакционной подготовкой: браузер получает готовые координаты, а сборке не нужен запрос маршрутизатора.

## Capabilities

### New Capabilities

Новые самостоятельные capabilities не требуются.

### Modified Capabilities

- `map-selection-sets`: собственная геометрия набора, её публикация, жизненный цикл на общей карте и перенос во встроенную схему.
- `map-geodata`: отображение одно- и двузначных номеров редакционных точек через общий формат.

## Impact

- Исходный запрос и разрешение реализации получены в текущей беседе с владельцем 27 октября 2026 года. Связанная задача: [#1180](https://github.com/silentroach/kpshelkovo/issues/1180), рабочая ветка `feat/map-selection-set-routes`. Владелец разрешил запуск `pnpm dev` для браузерной проверки.
- Это одно изменение механизма наборов с наполнением конкретного набора. В объём не входят редактор маршрутов, автоматическая оптимизация, навигационные подсказки, GPS, расписание групп и новые карточки мест.
- Затрагиваются `/apps/www/src/lib/map-selection-sets/`, общие схемы и адаптеры `/apps/www/src/lib/geometry/`, `/apps/www/src/components/places/PlaceMap.svelte`, общий renderer редакционных карт, данные набора и `/docs/editorial-maps.md`.
- Публичный endpoint `/map/data/selection-sets/<id>.json` получает необязательное поле геометрии. Наборы без неё сохраняют действующее представление и поведение. Новые зависимости и серверные API не нужны.
- Приёмка: проверки схем и жизненного цикла, сборка и typecheck, просмотр настоящей карты на узком и широком экранах. Для запуска `pnpm dev` требуется отдельное разрешение владельца. Production-приёмка для закрытия изменения не требуется.
- Исходный расчёт и ограничения точек находятся в [исследовании маршрута](/docs/research/halloween-2026-route-plan.md). Метки обозначают посещаемые участки; точные калитки и парковки для пеших блоков в эту задачу не добавляются.
