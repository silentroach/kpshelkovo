# Tasks

`design.md` пропущен по условию штатной схемы: перенос документации не вводит нового способа хранения, обработки или доставки файлов.

## 1. Владение правилами публикации

- [ ] 1.1 Подготовить ADR-019/020/021/023/024 к владельцу `public-media`: сохранить причины выбора, заменить нормативные повторы ссылками и проверить названия «оригинал»/web-master. Сверить по delta и текущей конфигурации стабильный origin, GET/HEAD, query, локальную 404, байты доказательств, даты, историю, конфликты недатированных PDF, неизменяемые news/reviews JPEG и различие GPS; для иллюстрации отзыва проверить авторскую позицию и `alt` в HTML/Markdown без автоматической обложки или аспекта. Исключение портретов проверить по `people-photos`/ADR-040 без дублирования их контракта.
- [ ] 1.2 Оставить точные команды, cache/JPEG-параметры и порядок проверки в [runbook](/ops/storage/public-media.md), направить `public-media-publisher` к владельцам требований и проверить согласованность всех ссылок. Проверить раздельность S3 immutable metadata и браузерного TTL, остановку небезопасного исходника вместо автоматической очистки и единственное разрешённое исключение перезаписи; выполнить `pnpm skills:check` и `pnpm test:agent-tooling` при правке skill, без операций с бакетом.

## 2. Общая приёмка
