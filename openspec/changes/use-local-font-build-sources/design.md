# Design

## Context

Мотивация — в [proposal](/openspec/changes/use-local-font-build-sources/proposal.md). База: master `2065393d802eb8383a1b11161d8983b2c25641ab`; рабочая ветка `fix/font-build-local-source`.

Общие определения `/packages/ui/fonts.ts` подключены к www, media и шести визуальным хостам. Fontsource разрешает удалённые метаданные, после чего `CachedFontFetcher` Astro 7.3.5 скачивает WOFF2 обычным `fetch` без повтора этого запроса. При сбое CI кеш отсутствовал, а PT Serif Cyrillic 700 завершился с `fetch failed`. Дальнейшая проверка URL дала HTTP 200 и 20916 bytes; лог не позволяет отличить DNS, TLS или иной транспортный сбой. Неправильный URL не подтверждён.

Применяются [ADR-034](/docs/decisions/034-native-css-architecture.md), [ADR-020](/docs/decisions/020-separate-media-error-app.md), [Font Budget](/docs/design/design-code-shelkovo.md#font-budget) и [web-font-loading](/openspec/specs/web-font-loading/spec.md). Владение CSS, границы приложений и публичный контракт не меняются.

## Goals / Non-Goals

**Goals:**

- После frozen install разрешать и копировать обязательные шрифты без запросов к Fontsource API/CDN даже с пустым font cache.
- Сохранить принятые бинарные файлы, font faces и generated fallback-поведение; не маскировать проблему выпуском неполного набора.

**Non-Goals:**

- Полностью офлайн-сборка сайта: удалённые изображения и установка пакетов имеют собственные сетевые зависимости.
- Пересмотр preload, loaded-типографики, наборов media/www, mobile KB CLS или повтор полной браузерной матрицы предыдущей миграции.
- CI retry-обвязка, pre-download скрипт, custom provider, ручные `@font-face`, новый кеш или общий redesign workflow.

## Decisions

### 1. Штатный local provider с установленными Fontsource-пакетами

Вернуть `@fontsource/fira-sans` и `@fontsource/pt-serif` как build-time зависимости `/packages/ui`, первоначально точные `5.3.0` — версии из lock-файла до миграции. Их использованные WOFF2 необходимо сверить по SHA-256 с принятым production artifact; расхождение нельзя выдавать за простую замену источника.

В существующем build-time модуле использовать `fontProviders.local()` и `options.variants`. Варианты строить из уже заданных весов и subsets; пути разрешать из `/packages/ui`, чтобы не зависеть от прямой доступности его зависимостей в app-root при pnpm. Каждый вариант получает конкретный WOFF2, weight, normal style и unicode-range соответствующего subset из метаданных того же пакета. Это небольшой конфигурационный mapper, не собственный provider или CSS-парсер. Набор media остаётся отдельным минимальным набором, без изменения fallback override.

Сохранить `sideEffects` пакета: новый build-time импорт не должен подключать CSS или runtime-инициализацию. Npm CSS не импортируется в приложения. Astro по-прежнему генерирует CSS и same-origin assets.

Альтернативы:

- **Повтор deploy / retry сборки:** может разблокировать разовый сбой, но сохраняет зависимость от CDN и не фиксирует удалённый `@latest`. Не выбран как устойчивое исправление.
- **Более тёплый Astro cache:** снижает частоту скачиваний, но cache miss остаётся допустимым и воспроизводит проблему.
- **Штатный `fontProviders.npm({ remote: false })`:** в установленном unifont 0.7.5 локальный CSS всё равно преобразует относительные WOFF2 URL в CDN URL (`resolveFromLocal`, `resolveUrlsToAbsolute`). Флаг запрещает только fallback загрузки CSS. Поэтому в данной версии это не решение для локальных бинарных файлов.

### 2. Не полагаться на Fontsource-specific subset metadata

`local()` Astro 7.3.5 не заполняет `meta.subset`, тогда как текущий `assertFontData` требует `fontData[*].subset`. Проверку адаптировать, а не оставлять заведомо падающей или молча отключать: конфигурация и адресный тест проверяют обязательные локальные варианты и их unicode-range; generated fontData проверяется по весам, стилям, WOFF2 и полноте ожидаемых faces. Отсутствующий файл должен завершать реальную сборку ошибкой, без сетевого fallback. Не вводить универсальный валидатор ради этого перехода.

### 3. Адресная приёмка вместо повторения миграции

Сохранить master font assets и generated font CSS как точку сравнения. С пустым font cache запретить обращения к Fontsource API/jsDelivr и собрать www/media; остальные сетевые источники сайта не объявлять офлайн. Одноразовое ограничение сети и сравнение artifacts не превращать в постоянный smoke-обход CI.

Подтвердить прежние девять www WOFF2 и два media WOFF2 по содержимому, а также эквивалентность font descriptors, unicode-range, порядка faces и optimized fallback CSS; новые хешированные URL/имена допустимы. Выполнить адресные font/guard тесты, lint/typecheck и актуализировать bundle YAML по правилам изменения сборки. Только если CSS-семантика отличается, сделать короткую браузерную проверку затронутого поведения; изменение видимого поведения требует возврата к владельцу.

Документация описывает новый источник и роль кеша; архив прежней миграции сохраняется как история. Workflow/nginx/CSP не меняются: источник сборки не меняет deploy-flow и внешние запросы браузера. Добавление production build на PR можно обсудить отдельно, оно не нужно для устранения CDN-зависимости.

## Risks / Trade-offs

- **Установка требует registry или pnpm store** → не заявлять независимость всего build/install от сети; устранена только отдельная стадия загрузки шрифтов.
- **Новая версия npm может содержать другие файлы/диапазоны** → точные версии, frozen lock и сравнение с принятым master; дальнейшие обновления проходят обычную приёмку.
- **Смена provider меняет generated имена и может повлиять на выбор metrics** → сравнить CSS и бинарные файлы; сохранить fallback и бюджет, не подменять сравнение успешным typecheck.
- **Конкретная нижележащая причина CI не раскрыта логом** → исправление убирает сетевой запрос целиком, а не предполагает конкретную проблему IPv4/IPv6/TLS.

## Migration Plan

После согласования сохранить план в рабочей ветке и отметить разрешение в #921. Реализация, документация и архив входят в один PR. Дополнительная production-приёмка не требуется: холодная сборка с запрещёнными font-origin запросами проверяет сам сбой до публикации; выкладка после человеческого merge остаётся владельцу.

Откат возвращает весь PR: конфигурацию, проверки, зависимости, lock-файл и документацию. Он восстановит Fonts API с прежним удалённым Fontsource provider и его сетевой зависимостью, не ручное подключение до #907.
