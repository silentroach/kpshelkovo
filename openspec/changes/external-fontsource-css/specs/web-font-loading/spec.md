# Spec Delta

## ADDED Requirements

### Requirement: Переиспользуемый внешний CSS шрифтов

Основной сайт SHALL подключать объявления веб-шрифтов через общий внешний CSS с origin страницы и кешируемым версионированным URL. HTML страниц MUST NOT повторять эти объявления inline. Пока CSS остаётся свежим в браузерном кеше, переход на другую страницу SHALL переиспользовать его без повторной передачи тела файла.

#### Scenario: Холодное открытие

- **WHEN** посетитель открывает страницу основного сайта без кеша
- **THEN** браузер получает внешний CSS шрифтов с origin страницы и затем загружает нужные тексту файлы шрифтов

#### Scenario: Переход на другую страницу

- **WHEN** посетитель открывает другую страницу основного сайта, а общий CSS шрифтов свеж в его браузерном кеше
- **THEN** страница использует тот же CSS без повторной передачи его тела и не дублирует объявления шрифтов внутри HTML

## MODIFIED Requirements

### Requirement: Читаемый текст во время загрузки шрифтов

Страницы SHALL показывать текст системным fallback до загрузки веб-шрифта и при её ошибке. Основной сайт и самостоятельная media 404 SHALL использовать системные fallback без коррекции метрик. Fallback MUST NOT обрезать текст или перекрывать управление. После загрузки веб-шрифтов SHALL применяться типографические роли дизайн-гайда.

#### Scenario: Медленная загрузка

- **WHEN** HTML и стили страницы доступны, а ответ с веб-шрифтом задерживается
- **THEN** заголовки, основной текст и подписи элементов управления отображаются доступным системным fallback до завершения загрузки файла

#### Scenario: Ошибка загрузки

- **WHEN** запрос веб-шрифта завершается ошибкой
- **THEN** текст остаётся читаемым, подписи элементов управления не обрезаны, а ссылки и кнопки доступны для использования

#### Scenario: Успешная загрузка

- **WHEN** нужные странице веб-шрифты успешно загружены
- **THEN** заголовки и основной текст отображаются соответствующими семействами и начертаниями из дизайн-гайда
