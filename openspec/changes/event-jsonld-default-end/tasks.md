## Workflow follow-up

- После разрешения реализации сохранить согласованные артефакты в рабочей ветке и связать change с issue по проектному процессу.
- После приёмки синхронизировать основные specs, архивировать change в той же ветке, выполнить `pnpm openspec:validate` и адресный повтор ревью документов.
- Открыть PR после разрешения публикации. Человеческое ревью и merge выполняет владелец.
