# Spec Delta

## ADDED Requirements

### Requirement: Объяснения отсутствующих значений читаются в видимой области

Объяснения отсутствующих расчётных значений SHALL полностью читаться на узком экране без горизонтального обрезания границей viewport и без обрезания прокручиваемой таблицей. Текст SHALL переноситься в пределах объяснения. Раскрытие SHALL сохранять связь с соответствующим значением, доступность с клавиатуры и сенсорным вводом, включая работу без JavaScript.

#### Scenario: Раскрытие на узком экране

- **WHEN** читатель раскрывает объяснение отсутствующего значения сенсорным нажатием на узком экране
- **THEN** текст объяснения переносится и читается без горизонтального обрезания

#### Scenario: Таблица прокручена

- **WHEN** читатель горизонтально прокручивает таблицу и раскрывает объяснение видимой кнопки
- **THEN** объяснение остаётся полностью читаемым без горизонтального обрезания или обрезания контейнером таблицы

#### Scenario: Клавиатура и отсутствие JavaScript

- **WHEN** читатель переводит фокус на кнопку объяснения с работающим или отключённым JavaScript
- **THEN** связанное объяснение раскрывается и читается полностью без потери фокуса

#### Scenario: Широкий экран

- **WHEN** объяснение раскрывается на широком экране
- **THEN** текст и связь с соответствующим значением сохраняются без обрезания
