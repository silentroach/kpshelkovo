# Данные интерактивной карты по слоям

## Context

Страница `/map/` загружает `/map/data/places.json`, а дороги получает отдельно. На этой ветке в справочнике 13 обычных, 10 инфраструктурных и 2 клубных места. Полный справочник занимает 2 282 байта Brotli, дорожный файл — 3 486. Разделение нужно для независимого включения данных; ускорение загрузки предстоит измерить.

## Goals / Non-Goals

Разделить доставку данных, сохранив существующие редакционные источники и публичный справочник. Не менять поведение участков, состав именованных наборов или стиль маркеров и линий.

## Decisions

1. **Три внутренних файла для карты.** При сборке разделить места с `show_on_map: true` по `mapLayer`. В `/map/data/layers/base.json` поместить обычные места, в `club.json` того же каталога — клубные, в `infra.json` — инфраструктурные и готовые линии дорог. Использовать один адаптер геометрии и мест, а не заводить редактируемые списки слоёв. Отдельный запрос `roads.json` больше не нужен. Как и дорожный ресурс, новые файлы служат рендереру ([ADR-011](/docs/decisions/011-public-surface-registry.md)); `/map/data/places.json` остаётся полным, включая `mapLayer`, для внешних потребителей.
2. **Прямой адрес без перебора файлов.** Вместе с базовыми местами выдавать короткое соответствие `slug → слой` только для опубликованных на карте мест двух дополнительных слоёв. По нему `h` и участники `set` находят нужный файл без запросов обоих слоёв. Индекс не содержит координат, геометрии или второй копии карточек. Скрытые и неизвестные места не открывают слой. Существующие контракты [ссылок](/openspec/specs/map-layer-links/spec.md) и [наборов](/openspec/specs/map-selection-sets/spec.md) сохраняются.
3. **Запрос и видимость независимы.** Запоминать текущую загрузку и успешный результат по слою в пределах открытой карты. Перед показом объектов, фокусом или вписыванием проверять актуальный выбор. Ручное включение клуба может вписать карту после получения данных, включение через `l` само по себе не двигает камеру. При ошибке разрешать новую попытку, не сбрасывая остальные слои.
4. **Атрибуция рядом с подложкой.** В файле слоя оставлять только геометрию дорог. Источник и лицензия остаются в исходном снимке и [руководстве](/docs/road-updates.md). Вместе с линиями показывать ссылку «© OpenStreetMap» на страницу авторских прав. Оформить её в одном стиле с текстовой атрибуцией Яндекса, не меняя её и не перекрывая её ссылок.

## Risks / Trade-offs

- Единый файл инфраструктуры означает, что при сетевой ошибке его запроса недоступны и дороги, и маркеры этого слоя. Карта и клубный слой продолжают работать; успешный ответ с пустыми линиями показывает инфраструктурные места без атрибуции дорог.
- Дублирование между публичным справочником и внутренними файлами приходится на статическую сборку. Генерировать их из одних данных по [ADR-013](/docs/decisions/013-raw-domain-public-data-boundary.md); интерактивная карта не скачивает оба представления.
- Дороги, участки и геометрия мест не должны попасть в клиентский JavaScript или в гидратацию вместо сетевого запроса. Сравнить реальные ответы и бандлы до и после.
