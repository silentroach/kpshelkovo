# Spec Delta

## ADDED Requirements

### Requirement: Адаптивное содержание KB индексируется один раз

Внутрисайтовый поиск SHALL индексировать мобильную авторскую версию адаптивного блока KB без повторной широкой копии и управляющих маркеров. Блок SHALL оставаться частью одной страницы по обычным правилам отбора KB. Переход к секции SHALL вести к общему видимому заголовку, а буквальные совпадения SHALL подсвечиваться в доступном экранном представлении по общим правилам поиска.

#### Scenario: Два представления содержат одни услуги

- **WHEN** индексируемая справка содержит широкую таблицу и мобильный список с одинаковыми сведениями
- **THEN** поисковый текст содержит мобильный список один раз, сохраняет данные для совпадений и не создаёт отдельного результата для каждой версии

#### Scenario: Результат открывают на разных экранах

- **WHEN** пользователь открывает результат с буквальным совпадением в адаптивном блоке на узком или широком экране
- **THEN** страница показывает соответствующую ширине версию, ссылка на секцию ведёт к общему заголовку, а совпадение подсвечивается в видимом содержании
