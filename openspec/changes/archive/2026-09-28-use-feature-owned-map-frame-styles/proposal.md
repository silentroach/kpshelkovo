# Proposal

## Why

После выноса общей рамки карты в отдельный CSS-файл в [PR #874](https://github.com/silentroach/kpshelkovo/pull/874) обнаружились три расхождения: белая панель подписи редакционной карты не повторяет скругление рамки, архивный план [#867](https://github.com/silentroach/kpshelkovo/issues/867) описывает прежнее локальное дублирование стилей, а новые глобальные `ui-*`-правила без слоя противоречат ADR-034. Нужно сохранить согласованный вид и заметные в обоих местах импорты, не превращая частный блок карт в общесайтовый примитив.

## What Changes

- Оформить рамку и подпись как явно подключаемый стиль функции карт с opt-in классами без префикса `ui-*`; сохранить единый CSS-источник и локальные размеры карт.
- Скруглить нижние углы непрозрачной панели подписи редакционной карты без обрезки всей фигуры и её интерактивных элементов.
- Зафиксировать узкое исключение для feature-owned CSS отдельным ADR с границей относительно ADR-034, обновить дизайн-гайд и связать исторический архив исходного изменения с последующим решением.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет: вид блока с картой уже закреплён в `place-card-presentation` и дизайн-гайде; меняются способ владения CSS и исправление несоответствия этому виду, а не долгоживущие продуктовые требования. `.openspec.yaml` содержит `skip_specs: true`.

## Impact

- Продолжение issue #867 в существующем PR #874. Затронуты CSS и классы редакционной карты в новостях и KB, карточка места, их тесты, дизайн-гайд, новый ADR и ссылка из архивного design на последующее решение.
- Данные мест, Markdown-источники, картографический runtime, действия, высота карт, публичные URL и зависимости не меняются. Отдельная production-приёмка не нужна; после локальной и браузерной проверки обычный PR сохраняет `Closes #867`.
