# Браузерная приёмка списка отзывов

Среда: macOS, agent-browser, headless Chrome; production `dist/www`, сервер `http://127.0.0.1:4361`, base `46526496ce8f8421abe08d323264a4673d72d2ea` и незакоммиченная реализация. Первый прогон использовал сборку 21:25:56; во время продолжения выполнена итоговая пересборка 21:28:34 после форматирования общих компонентов. Последующие запросы `/reviews/` в 21:28:40 и 21:29 получали её актуальные CSS-файлы. Версия Chrome и user agent — в `measurements.json`.

- **Не прошёл: 320 px, увеличение корневого размера текста до 200%.** Воспроизведение: открыть `/reviews/` с viewport 320×844, установить `document.documentElement.style.fontSize = '200%'`. `document.documentElement.scrollWidth` = 597 при `innerWidth` = 320. Диагностика показывает заголовок страницы `h1.ui-page-title`: ширина контейнера 176 px, `scrollWidth` 525 px; вводный абзац также переполняется (203 против 176 px). Артефакты: `list-320-text200.png`, `list-320-text200.json`, `overflow-investigation.json`. Это CSS-модель увеличения базового размера, не реальная настройка браузера «только текст»; источник переполнения — общая шапка страницы, а не карточки (у семи article scrollWidth = clientWidth = 256). Тем не менее на заданной странице горизонтальное переполнение подтверждено.
- **Прошёл: семь реальных отзывов и порядок элементов в DOM.** Заголовок и метаданные, цитата, затем при наличии оценки. Два отзыва без блока оценок, пять с тремя темами. См. `measurements.json`, `list-1440.png`, `list-390.png`, `list-320.png`. Сопоставление данных с источником и безопасная атрибуция отдельно не проверены.
- **Прошёл: доступные имена оценок в дереве доступности.** `Оценка N из 5`, тема рядом; фактическая озвучка скринридером не проверялась. См. `measurements.json`.
- **Прошёл частично: переход Enter.** Программно установлен фокус на ссылку первого заголовка, Enter открыл `/reviews/2026-08-22-promised-infrastructure-remains-in-booklets/`; `focus.png`. Табуляция и видимость фокуса визуально не оценены.
- **Прошёл: детальная страница, DOM и размеры.** Порядок дата → автор → район → статус, звёзды 20×20 px и gap 2 px; `detail-tree.txt`, `detail-measurements.json`, `detail.png`.

## Дополнительный прогон

Основная сессия уточнила сценарий: независимое переполнение общей шапки/intro при 200% зафиксировать отдельно и продолжить проверку карточек. Прочитаны корневые `comparison.md` и `design.md` change. Первый прогон выше сохранён с его ограничениями; результаты завершённой приёмки приведены ниже.

- **Прошёл — карточки при 200% базового размера и 320×844.** У всех семи карточек DOM-порядок summary → excerpt → aspects (если присутствуют); у проверенных заголовков, метаданных, цитат, подписей и рейтингов `scrollWidth ≤ clientWidth`, `scrollHeight ≤ clientHeight`, правая граница ≤ 320. `line-clamp` не применяется. По снимкам текст переносится, хотя отдельные длинные слова разрываются посередине. Доказательства: `cards-text200.json`, `cards-text200-full.png`, увеличенный фрагмент `cards-200-detail.png`. Это изменение root font-size, а не системная настройка text-only zoom; общая страница всё ещё переполнена из-за неизменённой шапки.
- **Прошёл — визуальное направление Г при 1440, 390 и 320.** Сравнены `list-{1440,390,320}.png` с одноимёнными `preview/images/list-*-after.webp`: композиция, порядок, отсутствие декоративных кавычек и вертикальной линии, рейтинги снизу совпадают; при 320 рейтинги становятся строками. Отличия: переносы строк и суммарная высота списка различаются, в том числе из-за реальной типографики с неразрывными пробелами; оценки при 320 визуально расположены правее, чем в примерке. Это визуальная сверка, не пиксельная идентичность.
- **Прошёл — настоящая клавиатура Tab и видимый focus.** На 390 px после пяти Tab шестой достигает первой карточки, седьмой — второй; у второй `:focus-visible`, outline 2 px solid, он виден на `tab-focus.png`; Enter открывает полный отзыв Морева. Свойства и href — `tab-focus.json`.
- **Прошёл — контраст на фактическом фоне.** Преобразование computed oklch через canvas в sRGB: фон RGB(250,251,248), muted RGB(95,106,98), отношение 5.43:1; заполненная звезда RGB(141,119,77), отношение 4.14:1. Расчёт WCAG по цветам без учёта сглаживания, `contrast.json`.
- **Прошёл — авторство и цитаты DOM.** Семь авторов и фрагментов совпали с `preview/quotes.json` после нормализации пробелов; `blockquote[cite]` у каждого совпадает со ссылкой заголовка. `attribution.json`. Семантическая достоверность контекста не устанавливается одной DOM-проверкой; ранее она была проверена при примерке, см. `comparison.md`.
- **Прошёл — синтетическое layout stress на 390 и 320 px.** В живом DOM изменены два реальных экземпляра: длинный заголовок с пробелами, анонимная подпись или длинное имя, отсутствие excerpt, одна или две оценки. Порядок summary → aspects, только оставленные темы, переполнения вложенных элементов по scrollWidth нет. `synthetic-layout.json`, `synthetic-320.json`, `synthetic-390.png`, `synthetic-320.png`. Это только временная DOM-имитация; не проверяет рендерер для данных anonymous/optional-полей и не покрывает неразрывные длинные слова; рендерер отдельно покрыт unit tests по информации основной сессии. При первом ошибочном запуске проверочный скрипт удалил всю layout-обёртку, после reload исправлен и артефакты перезаписаны; на production-данные и исходники это не влияло.

Новых подтверждённых дефектов карточек не обнаружено. Браузерная сессия закрыта; сервер не останавливался. Дополнительные временные ресурсы не оставлены, кроме запрошенных артефактов acceptance.
