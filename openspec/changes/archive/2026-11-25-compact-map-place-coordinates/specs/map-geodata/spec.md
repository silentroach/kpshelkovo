# Основная точка в JSON карты

## ADDED Requirements

### Requirement: JSON карты передаёт основную точку парой координат

В `/map/data/places.json` и JSON-файлах слоёв поле `coordinates` места SHALL содержать ровно два числа в порядке `[долгота, широта]`. Пара SHALL сохранять позицию основной точки с точностью по `public-coordinate-precision`, независимо от наличия дополнительной геометрии.

#### Scenario: Публикация основной точки

- **WHEN** место с долготой 37.716242 и широтой 55.060526 включено в общую карту
- **THEN** публичный справочник и соответствующий файл слоя содержат `coordinates: [37.716242, 55.060526]`
- **AND** маркер и переход по ссылке на место используют ту же позицию
