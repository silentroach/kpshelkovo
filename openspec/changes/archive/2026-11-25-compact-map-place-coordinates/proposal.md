# Координаты основной точки в JSON карты

## Why

В [задаче #1392](https://github.com/silentroach/kpshelkovo/issues/1392) приводим основную точку места к тому же порядку координат, который используют линии и другая геометрия общей карты.

## What Changes

- **BREAKING:** `coordinates` каждого места в `/map/data/places.json` и во внутренних файлах слоёв станет парой `[долгота, широта]` вместо объекта `{ lat, lng }`. Старый формат не поддерживаем.
- Сохраняем положение маркеров, редакционные записи, внутренние объекты мест, Markdown-карточки и формат снимка дорог.

## Capabilities

### New Capabilities

### Modified Capabilities

- `map-geodata`: формат основной точки в JSON карты.

## Impact

Меняются общий JSON-адаптер мест, схема и чтение данных картой. Адреса JSON и состав мест сохраняются. Работа идёт в [PR #1389](https://github.com/silentroach/kpshelkovo/pull/1389).
