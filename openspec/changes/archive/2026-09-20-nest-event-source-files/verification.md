## Результат реализации

- Семь исходников перенесены в папки мая, июня и сентября 2026 года. Git подтверждает все семь перемещений как 100% совпадение содержимого; frontmatter и body сохранены.
- Загрузчик читает вложенные файлы и проверяет путь вместе с московским месяцем начала. Ключ коллекции содержит путь; доменный ID получает только имя файла. Дубликаты между месячными папками доходят до предметной проверки и отклоняются.
- Девять проверок источников покрывают московскую границу месяца, период через год, неверное размещение, расхождение даты и обязательное описание. Две проверки загрузки покрывают стабильность идентичности при переносе и повтор ID; до адаптации загрузчика обе воспроизводили ошибку.
- Действующие инструкции согласованы с новой структурой. Указание плоского хранения осталось только в историческом design предыдущего архива.

## Приёмка

- `pnpm typecheck` — успешно.
- `pnpm test` — 1553 теста: 1436 приложения и 117 пакетных, включая events, новости, mentions/backlinks и публичные представления.
- `pnpm build` — успешно: 353 страницы сайта, 231 документ Pagefind. Первый запуск одновременно с typecheck столкнулся с записью общего Astro cache; последовательный повтор прошёл.
- На новой сборке разовое сравнение всех 12 наборов публичных идентификаторов и ICS дало полное совпадение с исходным снимком, включая SHA-256. Все календарные адреса ответили 200.
- Семь подробных страниц ответили 200 и сохранили canonical; у каждого мероприятия сохранился прежний DOM-якорь на странице дня.
- Ревью staged, unstaged и новых файлов, `oxfmt --check`, `git diff --check` и структурная валидация OpenSpec прошли. Проверены все сценарии delta spec; отдельного постоянного smoke-обхода сборки не добавлено.
- Основная `events-calendar` синхронизирована с delta spec. Change архивирован; итоговая валидация проверила 14 основных specs и 16 архивов без ошибок. Активных change нет.
