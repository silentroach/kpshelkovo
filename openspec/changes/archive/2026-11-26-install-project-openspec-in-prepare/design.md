# Design

## Context

[ADR-038](/docs/decisions/038-openspec-development-workflow.md) закрепляет локальную версию CLI и изоляцию личного профиля. Скрипт `openspec:generate` сейчас запускает `init` в пустом каталоге, затем копирует результат в репозиторий. В OpenSpec 2.1 проектная установка сверяет существующие файлы с версией релиза; пустой каталог лишает её этой возможности.

## Goals / Non-Goals

`pnpm install` восстанавливает базовые скиллы OpenSpec. Полный набор внешних скиллов по-прежнему устанавливает `pnpm agents:setup`.

## Decisions

- Вызывать из `prepare` существующий проектный скрипт с одной командой: `pnpm exec openspec init --scope project --tools agents --profile core --no-animation`. Целью служит сам ворктри. Сохранить изоляцию личного профиля и проверить состав после `init`, прежде чем считать установку успешной. Записать `skillsScope: project` в конфигурацию для последующих запусков OpenSpec.
- Убрать из Git только штатные `.agents/skills/openspec-*/` и `.agents/skills/.openspec-target`. Остальные скиллы и их lock-файл сохраняют своих владельцев. `agents:setup` получает готовую интеграцию после установки зависимостей, без повторного запуска генератора.
- Взять [pnpm 12.23.0](https://github.com/pnpm/pnpm/releases/tag/v12.23.0), закрепить версию в `packageManager` и обновить lock-файл самим pnpm. Заменить `ignoreScripts: true` на явные `false` в `allowBuilds` для зависимостей с установочными скриптами. Новые непроверенные скрипты остаются запрещены; строгая проверка pnpm сохраняется. Корневой `postinstall` продолжает настраивать `.githooks`.
- Включить `optimisticRepeatInstall: false`: без этого pnpm 12.23.0 пропускает `prepare`, когда зависимости уже установлены. Повторный запуск в готовом ворктри проверяет существующие скиллы, а при потере файла восстанавливает его. Для актуального набора дополнительное скачивание не нужно.

## Risks / Trade-offs

- Для восстановления скиллов в новом ворктри нужен источник релиза. Ошибка установки или неполный набор должны прерывать `prepare`.
- Повторный `pnpm install` выполняет хуки даже при готовом `node_modules`. Это цена восстановления скиллов той же командой. На временном проекте проверены оба режима pnpm и повторный `init` OpenSpec с готовым набором и запрещённым сетевым транспортом Git.

## Migration Plan

Убрать отслеживаемые копии вместе с переключением `prepare`, обновлением pnpm и документацией. После обновления ветки достаточно обычного `pnpm install`. При откате вернуть PR целиком и восстановить окружение через `pnpm agents:setup`.
