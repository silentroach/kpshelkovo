# Proposal

## Why

В [PR #1378](https://github.com/silentroach/kpshelkovo/pull/1378) тест установки в чистом каталоге не находит проектные скиллы OpenSpec 2.1. Хотим получать их при обычном `pnpm install` в каждом ворктри и перестать хранить копии релиза в Git. Задача: [#1399](https://github.com/silentroach/kpshelkovo/issues/1399).

## What Changes

- Обновить pnpm с 12.4.1 до 12.23.0 и оставить OpenSpec 2.1.0 из PR.
- Устанавливать базовый набор OpenSpec через корневой `prepare` в каталог текущего ворктри. Сохранить проектные настройки и собственные скиллы в Git.
- Разрешить хуки проекта, включая существующий `postinstall` для Git, сохранив запрет на установочные скрипты зависимостей.
- Использовать тот же шаг при полной установке агентского окружения и в CI.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `agent-tooling`: обычная установка зависимостей восстанавливает штатную интеграцию из закреплённого релиза без отслеживаемых копий скиллов.

## Impact

Изменятся настройки pnpm, lock-файл, скрипты установки, правила Git и инструкции для разработчиков. В новом ворктри установке скиллов нужен доступ к источнику релиза. Приложение и деплой не меняются.
