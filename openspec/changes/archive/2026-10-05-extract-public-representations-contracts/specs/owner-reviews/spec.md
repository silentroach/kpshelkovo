## MODIFIED Requirements

### Requirement: Публикация означает завершённую внешнюю проверку собственника

Раздел SHALL публиковать отзывы только текущих собственников участков или домов в Шелково после ручной проверки вне сайта. Документы проверки, контакты автора, черновики, внутренние заметки и отдельные статусы проверки SHALL не храниться в репозитории или на сайте и не попадать в публичные представления; сама публикация SHALL означать, что проверка уже состоялась. Правила отправки, модерации и обращения по поводу нарушений SHALL быть доступны по `/reviews/rules/` и в Markdown companion `/reviews/rules/index.md`.

Страница правил и страница каждого отдельного отзыва в HTML и Markdown SHALL содержать общий короткий отказ от ответственности из раздела «Отказ от ответственности» [правил публикации](/apps/www/src/data/review-rules.md#отказ-от-ответственности).

Канонические HTML URL индекса `/reviews/`, страницы правил `/reviews/rules/` и отдельных отзывов SHALL поддерживать получение соответствующего Markdown по `Accept: text/markdown`, сохраняя прямые Markdown companions. HTTP-выдача Markdown определяется [public-markdown-delivery](/openspec/specs/public-markdown-delivery/spec.md), а связи обнаружения — [public-content-discovery](/openspec/specs/public-content-discovery/spec.md).

#### Scenario: Проверка перед публикацией

- **WHEN** автор передаёт текст и сведения для подтверждения владения
- **THEN** проверка проходит вне сайта, а в репозиторий и публичные представления попадает только допущенный к публикации отзыв без материалов проверки и служебного статуса

#### Scenario: Отказ от ответственности доступен при чтении отзыва и правил

- **WHEN** читатель открывает отдельный отзыв или страницу правил в HTML либо Markdown
- **THEN** в самом открытом документе присутствует общий короткий отказ от ответственности из правил публикации

#### Scenario: Получение Markdown по каноническому HTML URL

- **WHEN** клиент запрашивает канонический HTML URL индекса отзывов, страницы правил либо опубликованного отзыва с `Accept: text/markdown`
- **THEN** он получает соответствующее Markdown-представление, доступное также по прямому URL companion, по правилам общих владельцев доставки и обнаружения
