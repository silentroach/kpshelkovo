# Примерка карточек «Сарафана»

Первая примерка для #1059 отклонена владельцем. Снимки ниже сохранены как история обсуждения; актуальный выбор описан в [design](/openspec/changes/archive/2026-10-16-refine-sarafan-card-presentation/design.md): убрать только серую подложку нейтрального пересказа, сохранив эмоджи и прежнюю плотность.

Снимки получены с production-страниц в отдельной браузерной сессии. Для вида «после» временно изменены DOM и CSS открытой страницы. Код приложения не менялся. Слева на сравнениях исходный вид, справа кандидат; подписи над изображениями относятся к стенду.

## Что примерили

- Прозрачный фон для всех отзывов, одинаковые интервалы, видимые слова тональности вместо эмоджи.
- Выжимки 16 px обычного цвета; источник 14 px обычного веса с названием площадки и датой.
- Переход по отдельной ссылке источника; текст выжимки можно выделить.
- Специализация 16 px и на телефоне; подписи контактов обычного веса, ссылки подчёркнуты.

## Проверка примерки

- В пяти случаях: Александр 1440/390, «Агромаш» 390, «Баха» 320, Игорь 320, горизонтального переполнения не было. Перед снимками шрифты завершили загрузку.
- В каждом случае сверены исходные и итоговые HTML выжимок, количество записей и URL источников: совпадают. Сохранились все 3 / 8 / 17 / 1 отзыва соответствующих карточек.
- Измеренные размеры выжимки и источника: 16 и 14 px; вес источника 400.
- Мобильный блок трёх отзывов Александра вырос с 509 до 637 px; восемь отзывов «Агромаша» с 967 до 1242 px. Высота увеличилась за счёт читаемости и видимых подписей.

Это визуальная проверка кандидата. Typecheck, тесты компонентов, сборка, контраст и окончательная клавиатурная приёмка относятся к будущей реализации.
