# Spec Delta

## ADDED Requirements

### Requirement: Запись позиции генплана сохраняет отдельные кадастровые идентичности

Редакционный набор SHALL хранить одну запись на подтверждённую группу обозначений генплана и нынешних кадастровых участков: один основной полный код и подтверждённые алиасы. Полный код соединяет префикс части `SHR`, `SHF`, `SHP` или `SHV` с коротким номером через дефис. Одна запись SHALL содержать один или несколько нынешних кадастровых участков, каждый со своим номером и геометрией из НСПД; она SHALL NOT представлять несколько номеров как один вымышленный кадастровый участок. Геометрия и номера SHALL находиться во frontmatter, заметки — в Markdown-теле. Один полный код и один нынешний кадастровый номер SHALL принадлежать не более чем одной действующей записи.

#### Scenario: Несколько обозначений одного участка

- **WHEN** два номера застройщика подтверждённо соответствуют одному нынешнему кадастровому участку
- **THEN** набор содержит один файл с основным кодом и алиасом, одной кадастровой геометрией и общими заметками

#### Scenario: Одно обозначение и несколько участков

- **WHEN** одна позиция генплана подтверждённо охватывает несколько самостоятельных нынешних кадастровых участков
- **THEN** набор содержит одну запись с одним кодом и всеми отдельными кадастровыми номерами и геометриями, без общего кадастрового номера

#### Scenario: Конфликт кода или кадастрового номера

- **WHEN** один основной код, алиас либо нынешний кадастровый номер назначен двум действующим записям
- **THEN** набор отклоняется с указанием конфликта, без произвольного выбора одной записи

### Requirement: Сведения позиции не подменяют сведения кадастровых частей

Статус, признаки и история цены, сообщённые генпланом об одной позиции, SHALL сохранять эту область действия при связи с несколькими кадастровыми участками. Они SHALL NOT становиться самостоятельными предложениями, статусами продажи или ценами каждого из составляющих участков. Если площадь группы указана, она SHALL происходить из площадей всех её нынешних составляющих по НСПД, а не из площади одного контура или неподтверждённой подписи генплана.

#### Scenario: Цена и статус одной позиции

- **WHEN** генплан сообщает один статус и одну цену позиции, охватывающей два кадастровых участка
- **THEN** редакционная запись хранит наблюдение о позиции целиком и не создаёт по отдельному предложению для каждого кадастрового номера

#### Scenario: Площади составляющих

- **WHEN** НСПД сообщает площади всех подтверждённых составляющих позиции
- **THEN** площадь позиции, если она хранится, соответствует сумме этих площадей с сохранением отдельных исходных значений

## REMOVED Requirements

### Requirement: Одна запись соответствует одному нынешнему участку

**Reason**: Связь одного обозначения с несколькими самостоятельными кадастровыми участками делает прежнее правило «одна запись — один кадастровый номер» неверным; его заменяет требование о записи позиции генплана с отдельными кадастровыми идентичностями.

**Migration**: Существующие записи с одним кадастровым номером остаются действительными; подтверждённые составные позиции получают явный перечень номеров и геометрий каждого участка.
