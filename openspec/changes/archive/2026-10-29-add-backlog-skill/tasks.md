# Tasks

`design.md` пропущен по условию штатной схемы: работа использует существующие каталог skills, bootstrap и `project-issues`; отдельного технического решения не требуется. Основа процесса — [ADR-038](/docs/decisions/038-openspec-development-workflow.md).

По указанию владельца тесты и сценарные прогоны в этой задаче не выполняются. Поведение оценивается сверкой инструкций; проверка подключения skill и структурная валидация сохраняются.

## 1. Правила и skill

- [x] 1.1 Уточнить короткий путь для небольших собственных skills в `/AGENTS.md` и примеры в `/docs/development.md`; проверить выбор маршрута для предметного skill в действующих разрешениях и для skill, меняющего полномочия, согласования или владельцев информации.
- [x] 1.2 Добавить `/.agents/skills/backlog/SKILL.md`, правило его вызова в `/AGENTS.md` и исключение в `/.gitignore`; подключить `project-issues` как источник правил публикации. Проверить загрузку skill и `pnpm skills:check` после добавления его файлов в Git-индекс.
- [x] 1.3 Сверить инструкцию с требованиями для новой подтверждённой проблемы с неизвестной причиной, существующего issue, неподтверждённого подозрения, ошибки собственной реализации и ограничения публикации. Проверить наличие правил поиска дубля, сохранения контекста, соблюдения разрешений и возвращения к исходной задаче.

## 2. Общая приёмка

- [x] 2.1 Выполнить `pnpm openspec:validate` и `pnpm skills:check`; сверить выполнение требований по инструкции и состав отслеживаемых файлов skill.
- [x] 2.2 Передать reviewer весь актуальный diff, включая новые файлы, согласованные требования и результаты проверок; разобрать замечания и выполнить адресный повтор после исправлений. При недоступности reviewer явно зафиксировать причину и выполнить оба прохода самопроверки по `/docs/development.md`.
