# Spec Delta

## ADDED Requirements

### Requirement: Точный номер участка дополняет общую поисковую выдачу

Общий поиск SHALL находить действующие участки по точному полному коду с дефисом и точному короткому номеру без учёта регистра. Совпавшие участки SHALL предшествовать обычным текстовым результатам, сохраняя доступность последних. Поиск участков SHALL NOT расширять совпадение до одного числового фрагмента, префикса номера или дополнительных вариантов записи. Для поиска SHALL NOT требоваться включение слоя карты, загрузка геометрии или отдельная редакционная страница участка.

#### Scenario: Полный и короткий номер

- **WHEN** пользователь вводит полный код либо короткий номер действующего участка в другом регистре
- **THEN** соответствующий участок находится перед обычными текстовыми результатами

#### Scenario: Частичный номер

- **WHEN** пользователь вводит только цифры или незавершённый номер, не равный обозначению участка
- **THEN** специальное совпадение участка не добавляется, а обычный текстовый поиск продолжает работать

### Requirement: Результат различает части Шелково и объединяет алиасы

Один поисковый результат SHALL соответствовать одному нынешнему участку и показывать основной полный код и название части Шелково. Одинаковые короткие номера разных частей SHALL давать отдельные различимые результаты. Совпадение по алиасу SHALL показывать основной код с пояснением совпавшего алиаса без дубля участка. Результат SHALL вести непосредственно к участку на общей карте по контракту `parcel-map`; догрузка выдачи SHALL сохранять этот переход и не добавлять повторные строки участка.

#### Scenario: Одинаковые номера разных частей

- **WHEN** короткий номер совпадает с участками нескольких частей Шелково
- **THEN** каждый нынешний участок представлен отдельной строкой с основным полным кодом и названием своей части

#### Scenario: Найден алиас

- **WHEN** запрос совпал с алиасом объединённого участка
- **THEN** выдача содержит одну строку с основным кодом, поясняет совпавший алиас и ведёт к тому же участку

#### Scenario: Догрузка текстовых результатов

- **WHEN** пользователь догружает общую выдачу, содержащую точные совпадения участков
- **THEN** участки остаются в начале без дублей, а следующие текстовые результаты доступны для перехода
