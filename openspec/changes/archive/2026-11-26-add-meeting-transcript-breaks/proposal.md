# Редакторские пометки между репликами

## Why

Когда запись прерывается или собеседники перебивают друг друга, пояснение редактора помогает понять ход разговора. Сейчас редактору приходится записывать пояснение как слова участника: у пометки появляются имя и таймкод.

## What Changes

- При вычитке редактор может поставить между репликами элемент `note` со своей подписью. Поводом может быть долгая пауза, пропуск неразборчивой речи или пояснение к продолжающемуся разговору.
- HTML показывает подпись внутри горизонтального разделителя; Markdown полной части сохраняет её там же по ходу разговора. У пометки нет спикера и таймкодов.
- Внутрисайтовый поиск индексирует речь, но не редакторские пометки.
- Поддержка формата добавляется без расстановки пометок и без изменений в данных встреч.

## Impact

Изменение касается загрузки YAML, страницы встречи, Markdown частей, поисковой разметки пометок и инструкции редактору. Действующие ссылки на реплики сохраняются. Отдельного issue про разрывы нет. Связанный [#1062](https://github.com/silentroach/kpshelkovo/issues/1062) описывает оформление обычных реплик.
