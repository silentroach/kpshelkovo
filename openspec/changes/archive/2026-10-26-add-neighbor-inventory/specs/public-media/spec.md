# Spec Delta

## ADDED Requirements

### Requirement: Фотографии инвентаря публикуются как неизменяемые подготовленные JPEG

Фотографии предложений `/ukogo/` SHALL использовать подготовленные JPEG web-master по действующему профилю runbook: полный кадр, корректная ориентация, без увеличения, EXIF/IPTC/XMP и GPS. Новые файлы раздела SHALL получать неизменяемые ключи `ukogo/<offer-id>/<photo-name>.jpeg`. Изменённый снимок SHALL получать новый ключ и URL; ссылки на подготовленные копии SHALL вести на media-origin с соблюдением общего правила переиспользования файлов.

#### Scenario: Редактор публикует фотографию предложения

- **WHEN** подготовленный снимок прошёл проверки публикации и доставки по `public-media`
- **THEN** предложение использует media URL, фактические размеры, текстовую альтернативу и необязательную подпись снимка

#### Scenario: Владелец прислал новый снимок

- **WHEN** редактор заменяет фотографию предложения другим изображением
- **THEN** публикуется новый ключ, ссылка предложения обновляется, а прежний объект не перезаписывается

#### Scenario: Снятие предложения

- **WHEN** предложение удалено из каталога
- **THEN** это само по себе не удаляет его публичные фотографии; удаление файлов остаётся отдельным действием по действующему контракту
