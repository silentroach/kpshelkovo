# Зафиксированная визуальная примерка

Снимок production-страниц от 16 октября 2026 года и предложенного оформления. Запускается отдельно от приложения, с сохранёнными CSS и шрифтами.

Из корня репозитория:

```bash
python3 -m http.server 4358 --bind 127.0.0.1 --directory openspec/changes/archive/2026-10-16-refine-kb-blocks/preview
```

Открыть `http://127.0.0.1:4358/`. Выбрать страницу и ширину. Для оферты выбран вариант «Договор и приложения»; сплошной список оставлен для сравнения. Вводный пункт находится отдельной строкой под «Содержание», перед колонками. Ссылки «Открыть отдельно» позволяют посмотреть страницу без масштабирования iframe.

## Файлы

- `before-*.html`: зафиксированные исходные страницы без скриптов приложения.
- `after-*.html`: визуальные варианты. Актуальная оферта: `after-offer-grouped.html`; инструкция: `after-gas-expanded.html`.
- `proposal.css`: читаемый исходник предложенных стилей, встроенный в подготовленные HTML.
- `build.mjs`: воспроизводит варианты из сохранённых `before-*.html` и CSS. Использует установленный workspace-пакет `happy-dom`, запросов к production не делает.
- `static/`: копии CSS и шрифтов страницы. Лицензии шрифтов находятся в `licenses/`.
- `index.html`, `preview.css`, `preview.js`: оболочка сравнения.

После изменения примерки HTML можно пересобрать:

```bash
node openspec/changes/archive/2026-10-16-refine-kb-blocks/preview/build.mjs
```

## Границы применения

Это визуальный материал. Скрипт работает с готовой HTML-копией, знает состав примера и использует образец даты. Production-реализация следует [design](/openspec/changes/archive/2026-10-16-refine-kb-blocks/design.md) и строит TOC из авторских аннотаций Markdown. Копировать обработку HTML или определение групп по словам из прототипа в рендер не следует.

Сохранённые HTML уже готовы к просмотру; установка зависимостей нужна только для повторной генерации. CSS и шрифты локальные. Иллюстрация газовой инструкции и внешние ссылки сохраняют публичные адреса; просмотр оглавления и блока оригинала от них не зависит. Меню, поиск и другие скрипты приложения в снимках не участвуют.

Шрифты Fira Sans и PT Serif получены из локально опубликованных Fontsource-ресурсов сайта; оригинальные тексты лицензий сохранены без изменений.
