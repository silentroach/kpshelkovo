# Spec Delta

## MODIFIED Requirements

### Requirement: Отказ данных допускает локальный повтор

При успешно загруженном клиентском коде отказ данных сравнения SHALL допускать повтор без обновления страницы. Отказ API карты SHALL иметь локальное восстановление и не блокировать работающие список и фильтры сравнения. При одновременном отказе кода и данных сравнение SHALL предлагать полное обновление страницы.

#### Scenario: Не загрузились только данные сравнения

- **WHEN** компонент сравнения загрузился, запрос данных завершился ошибкой, затем пользователь повторил загрузку при восстановленной доступности данных
- **THEN** сравнение становится интерактивным без перезагрузки документа

#### Scenario: Не загрузились и код, и данные

- **WHEN** оба запроса сравнения завершились ошибкой независимо от порядка завершения
- **THEN** сообщение подсказывает обновить страницу средствами браузера, а кнопка локального повтора отсутствует

#### Scenario: Ошибка поисковых данных

- **WHEN** загруженный поисковый интерфейс столкнулся с отказом данных Pagefind
- **THEN** восстановление следует требованию «Ошибка поисковых данных предлагает обновить страницу»

#### Scenario: Ошибка карты

- **WHEN** API карты сравнения не загрузился, а список уже интерактивен
- **THEN** список и фильтры продолжают работать, а повтор загрузки доступен в области карты

## ADDED Requirements

### Requirement: Ошибка поисковых данных предлагает обновить страницу

При отказе поисковых данных поиск SHALL показывать ошибку и текстовую подсказку обновить страницу средствами браузера, доступные вспомогательным технологиям. В этих состояниях сайт SHALL NOT предлагать кнопки локального повтора или обновления и SHALL NOT автоматически перезагружать страницу. После восстановления доступности данных обычное обновление SHALL позволять снова пользоваться поиском; сохранение диалога и запроса не гарантируется.

#### Scenario: Не загрузилась первая выдача

- **WHEN** загруженный поисковый интерфейс столкнулся с отказом данных при получении первой выдачи
- **THEN** пользователь видит сообщение об ошибке и предложение обновить страницу без кнопок восстановления; сообщение и подсказка объявляются вспомогательным технологиям
- **AND** диалог можно закрыть с возвратом фокуса к элементу открытия, а страница не обновляется автоматически

#### Scenario: Не загрузились следующие результаты

- **WHEN** часть результатов уже показана, а догрузка следующих завершилась ошибкой
- **THEN** показанные результаты и их ссылки остаются доступны, рядом с ними появляется и объявляется подсказка об ошибке и обновлении страницы без кнопок восстановления
- **AND** диалог можно закрыть с возвратом фокуса к элементу открытия, а страница не обновляется автоматически

#### Scenario: Восстановление после отказа поисковых данных

- **WHEN** после отказа первой выдачи или догрузки данные снова доступны и пользователь обновляет страницу средствами браузера
- **THEN** поиск работает при новом открытии и вводе запроса
