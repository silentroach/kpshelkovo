# Spec Delta

## ADDED Requirements

### Requirement: Главная показывает комплект изображений по сезону

Главная SHALL выбирать один комплект из дневной панорамы, ночной панорамы и обложки для ссылок по дате сборки в `Europe/Moscow`. С 1 ноября до 1 апреля SHALL использоваться зимний комплект, в остальное время — комплект без снега.

#### Scenario: Начало зимнего периода

- **WHEN** выходит сборка от 1 ноября по московскому времени после публикации октябрьской сборки
- **THEN** обе панорамы и обложка в метаданных главной меняются на зимние

#### Scenario: Конец зимнего периода

- **WHEN** выходит сборка от 1 апреля по московскому времени после публикации мартовской сборки
- **THEN** обе панорамы и обложка в метаданных главной меняются на комплект без снега

#### Scenario: Дневная и ночная панорамы

- **WHEN** посетитель открывает главную с включённым JavaScript
- **THEN** панорама выбирается по текущей освещённости в Шелково из опубликованного комплекта
- **AND** без JavaScript доступна панорама того же комплекта, выбранная по освещённости на момент сборки
