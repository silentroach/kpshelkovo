# Proposal

## Why

На главной круглый год видна зелёная панорама. Первый этап [#1396](https://github.com/silentroach/kpshelkovo/issues/1396) добавит зимний вид, не меняя панораму в остальные месяцы.

## What Changes

- С ноября по март включительно по московскому времени главная получает зимние дневную и ночную панорамы и зимнюю обложку для ссылок. С апреля по октябрь остаётся текущий комплект.
- Сезон определяется при сборке. Выбор дня и ночи по освещённости в Шелково сохраняется.
- Отдельные изображения для весны и осени в этот этап не входят.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `homepage`: сезонный выбор комплекта изображений главной.

## Impact

Меняются только изображения и метаданные главной. Для смены сезона используется действующая ежедневная публикация; новый серверный или клиентский механизм не нужен. Этот этап не закрывает #1396.
