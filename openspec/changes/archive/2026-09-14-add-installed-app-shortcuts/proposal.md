## Why

Жителю нужно открывать новости, статус сервисов и базу знаний прямо из меню иконки установленного сайта, без промежуточного перехода на главную. В [issue #724](https://github.com/silentroach/kpshelkovo/issues/724) предложены manifest shortcuts; после обсуждения владелец выбрал эти три раздела вместо первоначальных «Статус», «Сарафан» и «Карта».

## What Changes

- Добавить общий web app manifest для «Шелково Онлайн» с коротким именем «Шелково», существующими иконками и цветом темы.
- Задать обычный запуск с `/`, область приложения `/` и режим `standalone`.
- Объявить ровно три shortcuts в порядке приоритета:
  1. «Новости» → `/news/`.
  2. «Статус» → `/status/`.
  3. «База знаний» → `/kb/`.
- Подключить один manifest через общий layout, чтобы установку можно было начать с любой страницы сайта.
- Использовать штатную добровольную установку браузером. Собственные предложения установки, service worker, офлайн-кеш, push, персонализация пунктов и изменение навигации страниц не входят в объём.
- Ориентироваться на Chrome Android и Safari macOS. Отображение системного меню зависит от браузера и ОС; на iOS manifest shortcuts не обещаются.
- Принимать реализацию по локальным проверкам конфигурации, сборки и целевых страниц. Владелец отказался от обязательной проверки установленного приложения и production-приёмки.

## Capabilities

### New Capabilities

- `installed-web-app`: общий manifest сайта, параметры обычного запуска и три прямых перехода из меню установленного приложения.

### Modified Capabilities

Нет. Существующие specs описывают процесс и инструменты; их требования не меняются.

## Impact

- `apps/www`: новый статический JSON endpoint manifest и ссылка на него в `src/layouts/BaseLayout.astro`; готовые PNG из `public/` и цвет из `src/lib/browser-colors.ts` используются повторно.
- Публичная поверхность: новый `/manifest.json`; HTML-адреса разделов сохраняются.
- Зависимости и клиентский JavaScript для этой возможности не добавляются. Действующие статическая сборка, доставка JSON и CSP подходят для same-origin manifest.
- Задача остаётся пилотом перехода [#734](https://github.com/silentroach/kpshelkovo/issues/734): после отдельного разрешения реализации документы и отметка в issue передаются новой сессии до изменения кода. Результат настоящей передачи фиксируется для [#735](https://github.com/silentroach/kpshelkovo/issues/735).
