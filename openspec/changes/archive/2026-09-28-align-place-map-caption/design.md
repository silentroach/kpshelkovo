# Design

## Context

На `/map/[slug]/` адрес уже находится в `<figcaption>` под `PlacePreview`, но оформляется локальным правилом с отступом `0.75rem`. В `NewsPhotos.astro` подпись использует `ui-media-caption` и отступ `0.5rem`; глобальный стиль задаёт ей типографику. Дизайн-гайд уже называет адрес подписью под превью. Владение локальными стилями следует [ADR-034](../../../../docs/decisions/034-native-css-architecture.md).

## Goals / Non-Goals

**Goals:** использовать существующий стиль подписи и расстояние до карты без изменений её рамки или структуры ссылок.

**Non-Goals:** менять оформление новостей, данные мест, карту, её действия или создавать новый общий компонент.

## Decisions

- Добавить к существующему `<figcaption>` класс `ui-media-caption`, а локальное правило оставить только для отступа `0.5rem`. Так карточка разделит типографику с новостями и сохранит локальное расстояние до карты; дублировать общие свойства в scoped CSS не требуется.
- Не переносить адрес внутрь `PlacePreview`: он относится к карточке места, остаётся вне рамки карты и не влияет на элементы SDK. Не менять URL маркера и штатную кнопку.

## Risks / Trade-offs

- Общий стиль подписи применяется к адресу, который может быть длиннее новостной подписи → проверить перенос текста на узком экране и отсутствие горизонтального переполнения.
