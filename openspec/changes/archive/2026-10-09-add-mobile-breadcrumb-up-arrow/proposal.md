# Proposal

## Why

В [issue #1012](https://github.com/silentroach/kpshelkovo/issues/1012) единственная мобильная ссылка в хлебных крошках не подсказывает, что ведёт на верхний уровень. Декоративный знак влево уточнит назначение без изменения адреса и навигационной модели.

## What Changes

- Показывать знак влево в стиле существующего разделителя, если после сокращения пути виден ровно один элемент и он является родительской ссылкой.
- Скрыть знак от скринридеров и сохранить нативную ссылку, её имя и адрес.
- Сохранить несколько мобильных крошек, единственный нессылочный элемент, средний и desktop-режимы без изменений.
- Уточнить это исключение в действующем дизайн-гайде и README UI; использовать SSR и scoped CSS без клиентского кода.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `site-navigation`: исключение для единственного ссылочного родителя в мобильном блоке крошек.

## Impact

- `/packages/ui/src/Breadcrumbs.astro`, существующие визуальные тесты и стенд, `/packages/ui/README.md`, раздел крошек в `/docs/design/design-code-shelkovo.md`.
- Мобильная граница остаётся `<40rem` по дизайн-гайду; полная microdata и режим `linkLast` сохраняются.
- Shared-компонент требует проверки затронутых разделов сайта. Новых зависимостей, клиентских импортов и публичных URL нет.
- Отдельная production-приёмка не требуется; достаточны локальный стенд и собранный сайт.
- Реализация #175, #957, #173 и #999 не затрагивается; контроль их страниц выполняется без правки.
