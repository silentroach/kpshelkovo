# Как присоединить местный проезд к сети

## Context

[Принятый снимок](/apps/www/src/data/road-sources/osm.json) хранит OSM-линии в виде упорядоченных ссылок на узлы. Два проезда связаны, если у них общий узел. Приём новой выгрузки целиком заменяет снимок; правка его вручную пропадёт. Геометрия для экрана уже лишена идентификаторов узлов, поэтому добавлять проезд в готовый JSON карты поздно.

## Goals / Non-Goals

Собрать одну сеть, в которой сохраняются исходные OSM ID, редакторское происхождение локальных линий и связи между ними. Обновление снимка, правила отбора `highway` и интерфейс карты сохраняются. Планировщик в этом change не создаём.

## Decisions

1. Хранить проезды в `apps/www/src/data/road-sources/local-roads.yaml`. У каждой записи свой стабильный ключ; рядом комментарий, кто или что подтверждает проезд. Геометрию задаёт последовательность точек: ссылка на OSM-узел на известном стыке, собственные координаты `[долгота, широта]` на изгибах. Координата без ссылки не склеивает дороги, даже если совпадает с другим узлом на рисунке.
2. После чтения обоих источников построить общую сеть по [ADR-013](/docs/decisions/013-raw-domain-public-data-boundary.md). Локальные дороги и их внутренние точки различать с объектами OSM по источнику идентификатора. Общий узел брать из снимка, чтобы сдвиг перекрёстка не оторвал привязанный конец. В карту передавать прежнюю экранную геометрию с теми же обрезкой, поправкой и атрибуцией OSM; цвета покрытий относятся к соседнему change.
3. Оставить ручной просмотр кандидата по [руководству](/docs/road-updates.md). При заметной перемене достаточно двух изображений в одном масштабе и кадре; их можно подготовить из двух версий сети. При полном или частичном совпадении объяснить владельцу, какая линия заменяет какую часть, и дождаться явного ответа **до** редактирования локальной записи. Отдельный детектор дублей по расстоянию не нужен.

## Risks / Trade-offs

- Если узел привязки исчез, показать ошибку с ключом проезда и ID узла. Проверять привязки кандидата до замены рабочего снимка: потерю узла нельзя исправить автоматической привязкой к ближайшему.
- При переносе первого проезда привязать концы к настоящим перекрёсткам, а не к иконке подстанции. Если изображение не позволяет однозначно восстановить форму или примыкание, показать наложение владельцу перед записью.

## Migration Plan

Добавить локальный источник и его чтение вместе с первой записью. Формат и содержимое принятого снимка ради этого не меняются.
