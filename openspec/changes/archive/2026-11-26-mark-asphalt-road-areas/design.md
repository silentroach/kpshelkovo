# Области покрытия и линии на карте

## Context

[Сборка дорог для карты](/apps/www/src/lib/roads/map-public.ts) обрезает линии по территории Шелково и сдвигает их для совмещения с Яндекс Картами. Клиент получает готовую геометрию с инфраструктурой. На [схемах ОК](https://kpshelkovo.online/kb/ok/asphalt-plan-2026/) цвет означает год или этап укладки; жителю на карте нужно знать само покрытие.

## Goals / Non-Goals

Редактор может перенести новую схему или указание владельца правкой одного файла. Историю укладки не восстанавливаем. В интерфейсе остаётся переключатель «Инфраструктура», без режима редактирования дорог.

## Decisions

1. В `apps/www/src/data/road-sources/asphalt-areas.yaml` хранить список многоугольников в координатах `[долгота, широта]` для всех четырёх частей. Комментариями указывать ориентир и ссылку на статью КБ для одного блока или группы. Схему в Way ID не переводить: у длинной прямой между соседними узлами может оказаться несколько межей, а OSM может поменять сами узлы. Теги `surface` из снимка оставлять исходными данными; для этой разметки действует правило областей.
2. Определять покрытие по объединению областей. Сначала обрезать линии по границе показа, затем разделить оставшуюся геометрию на однородные фрагменты **до** сдвига и округления. В [геометрии обрезки](/packages/geo/src/line-clip.ts) уже рассчитываются точки пересечения, но наружные фрагменты отбрасываются. В `packages/geo` переиспользовать точки разреза для обеих частей: общей точкой заканчивается щебень и начинается асфальт. Линию вдоль границы относить к асфальту. Новые вершины принадлежат только отрезкам покрытия.
3. Передавать две группы готовых линий в том же файле инфраструктуры по [ADR-013](/docs/decisions/013-raw-domain-public-data-boundary.md). Сцена общей карты по [ADR-039](/docs/decisions/039-shared-yandex-maps-runtime-and-preview.md) рисует обе группы без обработки нажатий. Ни полигоны, ни библиотека обрезки в браузере не нужны.
4. Щебень показать тонкой охристой линией, асфальт — чуть более широкой серо-синей. Тёплый и холодный оттенки различают покрытия без тяжёлой тёмной обводки. Обе линии сплошные: пунктир на карте легко принять за тропу или разрыв. Компактная легенда с образцами находится справа вверху, на уровне управления слоями. Она видна только вместе с линиями дорог и не занимает место атрибуции внизу. Толщину и цвета хранить в [дизайн-гайде](/docs/design/design-code-shelkovo.md).

## Risks / Trade-offs

- **Планы повёрнуты и используют разные цвета.** За основу взять схемы от 2 октября; сверить со [схемами от 21 августа](https://kpshelkovo.online/kb/ok/asphalt-plan-2026-previous/). Владелец подтвердил выполнение отмеченных работ, включая зелёные отрезки октября. Сопоставлять по номерам участков, развилкам и изгибам, а не по стороне листа. Если версии расходятся и принадлежность проезда неясна, показать фрагмент владельцу.
- **Слишком широкий контур захватит соседнюю улицу.** Весь квартал обводить только если заасфальтированы все его дороги; отдельные улицы отмечать полосами с запасом по ширине, проверяя примыкания. При заметных изменениях сети показать два вида одного места при одинаковом масштабе; метрики и автоматический порог не требуются.

## Migration Plan

Выпустить данные, подготовку геометрии и оба стиля вместе. Снимок OSM не требует миграции; откатить код и данные покрытия вместе.
