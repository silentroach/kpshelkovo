## Разрешение и рабочее состояние

- Владелец разрешил реализацию и `pnpm dev` в беседе 27 октября 2026 года; затем отдельно подтвердил использование `pnpm dev` для проверки карт.
- Задача: [#1180](https://github.com/silentroach/kpshelkovo/issues/1180). Ветка: `feat/map-selection-set-routes`.
- Согласованные артефакты сохранены в коммите `8bea7bc8`; отметка разрешения добавлена в issue. Публикация ветки выполняется после проверок.

## Данные и адресные проверки

- Baseline `pnpm bundle:analyze` завершён до правок клиентского графа. Исходные `client.yaml` и `assets.yaml` сохранены во временном рабочем каталоге для сравнения.
- Адресные проверки загрузчика наборов, общего resolver, HTML/companion, mapper геометрии и renderer: 117 тестов в шести файлах прошли после объединения первых правок. Новые проверки жизненного цикла выполняются отдельно после завершения соответствующей подзадачи.
- Ошибочный первый запуск Vitest из корня без конфигурации приложения не смог разрешить alias и Svelte. Повтор выполнен штатно через `pnpm --filter @shelkovo/www exec vitest run ...`; конфигурация проекта не менялась.
- Svelte autofixer для изменённого `PlaceMap.svelte` не обнаружил ошибок. Его рекомендации относятся к существующим нерективным SDK-коллекциям, `bind:this` и class-директивам; они не меняются в рамках маршрута.

## Экспорт маршрута

- Через исследовательскую страницу на localhost повторно запрошен полный автомобильный маршрут без M48: 19 точек, 18 переездов, 68 сегментов, 9 647 м, 37,1 минуты чистого движения.
- Экспорт сохранён отдельно от прежнего исследования с M48. Ключ читается из локального окружения и не включается в набор или отчёт.
- Для публикации сохраняются реальные сегменты дорог; разрывы не соединяются прямыми линиями. Расположение меток домов берётся из подготовленных точек подписей кадастрового слоя, положение дороги не сдвигается.

## Уточнения во время браузерной приёмки

- Владелец просмотрел карту и попросил ставить номера на ближайшей дороге у дома, а для соседних домов выбирать общую точку остановки. Согласованы 15 остановок у домов и точка 16 у финала; блоки Вилладжа и Фореста объединены.
- Владелец отдельно попросил убрать подписи, состоящие из номеров участков. У точек 1–15 остаются номера без `iconCaption`; состав домов хранится в `description`. Подпись финала сохраняется.
- Предыдущий экспорт и редакторская вычитка 19 подписей относятся к первой версии. Новая дорожная линия повторно запрошена через 16 точек: 9 560 м и 36,4 минуты чистого движения.
- До этих уточнений `pnpm test` прошёл во всех восьми пакетах с тестами; приложение: 270 файлов, 2380 тестов. `pnpm typecheck` и `pnpm build` прошли. После исправления приоритета номерного маркера адресные 25 тестов renderer и lifecycle прошли.
- Декоративные цифровые метки получили приоритет над обычными маркерами, поскольку значок парка перекрывал номер финиша. Правило записано в действующем дизайн-гайде. Первая проверка настоящей карты выполнена через разрешённый `pnpm dev`, а не production-preview.

## Итоговые данные и поведение

- Один `LineString` содержит 292 вершины, точно совпадающие с последовательностью нового полного дорожного экспорта после округления и удаления соседних повторов. Сверены все 16 координат остановок и последовательность номеров, все 18 участников покрыты один раз в составе остановок, M48 отсутствует.
- Компактный исходный JSON занимает 9 890 байт, подготовленный публичный JSON занимает 9 968 байт: одна линия и 16 точек. У остановок 1–15 нет `iconCaption`, у финала сохранена прежняя подпись.
- Основной агент исправил результат worker: при первой записи обновлённой версии массив координат линии оказался пустым, хотя JSON разбирался. Вставлена полная проверенная линия, затем результат независимо сверен с экспортом. Промежуточные ошибки dev во время замены файла не относятся к итоговой сборке; для конечной проверки dev-стек перезапущен после готовности данных.
- `editorial-reviewer` вычитал исходные подписи без замечаний и адресно проверил их удаление. Видимая подпись финала не менялась; названия всех 18 домов сохранены в скрытых описаниях.
- Браузер: номера 1–16, единственная подпись финала, отсутствие ошибок; при выключении Вилладжа все 16 меток остаются, «Снять набор» удаляет их и `set`. Прямая ссылка с `p=SHV-G36` сохраняет фокус у Вилладжа, `p=SHF-M70` у Фореста, `h=forest-park` фокусирует парк. Ссылка на карточку парка доступна, проверена также попаданием указателя.
- Свидетельства: [общий вид 1440×900](/openspec/changes/archive/2026-10-27-add-map-selection-set-routes/acceptance/desktop.webp), [390×844](/openspec/changes/archive/2026-10-27-add-map-selection-set-routes/acceptance/mobile.webp), [общая остановка Вилладжа](/openspec/changes/archive/2026-10-27-add-map-selection-set-routes/acceptance/village.webp), [общая остановка Фореста](/openspec/changes/archive/2026-10-27-add-map-selection-set-routes/acceptance/forest.webp).

Новых клиентских зависимостей и кода схемной проверки нет. Изменение сжатых размеров соседних чанков на единицы байт связано с хешами импортируемого общего модуля.
