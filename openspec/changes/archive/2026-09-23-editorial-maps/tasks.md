# Tasks

Реализация начинается после отдельного разрешения владельца на подготовленные артефакты и отметки в issue со ссылкой на их коммит. Чекбоксы ниже относятся к реализации и её приёмке; подготовка этого плана их не завершает.

- [x] 1.1 Исследовать печать существующей сцены SDK на минимальном пробнике production-сборки и отдельном CDP-пробнике; зафиксировать фактический вывод нескольких карт ниже экрана, ручной кадр, холодную загрузку и замедленную сеть, поведение `printBackground:false`, потерю логотипа на действующем CSS и проверенный CSS-кандидат. Отделить эти наблюдения от неподтверждённой системной печати, Safari, печати до готовности карт и будущего print resize в `docs/research/editorial-maps/print-acceptance.md`.
- [x] 1.2 До изменения поисковой разметки выбрать затронутые запросы и соседние формулировки, снять выдачу существующего UI по `site-search`: URL, порядок, snippets, highlights и переходы. Сохранить краткую исходную запись для сравнения с задачей 6.2; приёмочные материалы держать отдельно от публикуемого контента.
