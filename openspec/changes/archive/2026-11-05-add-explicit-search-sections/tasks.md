Публичные adapters сохраняют свой прежний состав полей.
- [x] 2.2 Добавить ID, plain-text название секции с полной датой и отступ прокрутки к индексируемому summary в ContactReviews; компонентные тесты подтверждают цель, сохранность текста/внешней ссылки и отсутствие служебного окружения в body. Сверить принятое описание этой разметки с design.
