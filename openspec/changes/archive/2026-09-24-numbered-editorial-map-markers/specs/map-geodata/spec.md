# Spec Delta

## ADDED Requirements

### Requirement: Редакционные точки поддерживают цифровые метки внутри маркера

Редакционный GeoJSON SHALL принимать `iconContent` у точки как строку из одной цифры `0`–`9` и показывать её внутри стандартного круглого маркера. `iconCaption`, если задан, SHALL оставаться отдельной подписью точки; точка без `iconContent` SHALL сохранять обычный вид. Значение SHALL сохраняться в публичной геометрии места и отображаться как обычный текст без интерпретации HTML или Markdown. `iconContent` с иным содержимым либо у объекта, не являющегося точкой, SHALL отклоняться с диагностикой источника, объекта и поля.

#### Scenario: Нумерованные точки и подписи

- **WHEN** коллекция содержит точки с цифровым `iconContent`, часть из которых имеет `iconCaption`, и точку без `iconContent`
- **THEN** цифры видны внутри соответствующих кружков, заданные подписи видны рядом, а ненумерованная точка остаётся обычной

#### Scenario: Геометрия места для внешнего потребителя

- **WHEN** дополнительная геометрия места содержит нумерованную точку
- **THEN** публичная коллекция сохраняет её `iconContent`, а отображаемая точка показывает тот же номер

#### Scenario: Недопустимая цифровая метка

- **WHEN** `iconContent` содержит более одного символа, нецифровую строку либо задан у линии
- **THEN** публикация останавливается с указанием источника, объекта и поля `iconContent`
