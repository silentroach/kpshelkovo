# Design

## Context

См. [proposal.md](proposal.md). `map` в новости и соседний GeoJSON места проходят общую строгую raw-схему, mapper и readonly-модель; карта в HTML проверяет сериализованную модель повторно. Геометрия места дополнительно проходит отдельные public-схему и адаптер, а затем обратное преобразование для карты мест. Общий `createEditorialMapObjects` рисует точки обоих источников; подпись `iconCaption` уже отделена от круглого `.ui-map-marker`.

Подход опирается на [ADR-013](../../../docs/decisions/013-raw-domain-public-data-boundary.md) (раздельные raw, domain и public), [ADR-028](../../../docs/decisions/028-markdown-first-places-map.md) (единый формат редакционных геоданных и стандартный маркер), [ADR-034](../../../docs/decisions/034-native-css-architecture.md) (app-owned стили) и [ADR-039](../../../docs/decisions/039-shared-yandex-maps-runtime-and-preview.md) (общая отрисовка поверх существующего runtime).

## Goals / Non-Goals

**Goals:** Передавать метку без потери через все уже существующие границы данных и рисовать её как текст по центру точки в обеих картах. Сохранить исходный блок новости в Markdown companion и согласованное публичное представление геометрии места.

**Non-Goals:** Отображение произвольного HTML из Конструктора Яндекса, новый тип маркера или легенда, интерактивность точки и изменение геометрии маршрута.

## Decisions

1. В `RawEditorialGeometrySchema` принять `properties.iconContent` только в форме строки из одной ASCII-цифры `0`–`9`; попытку задать её у линии или области отклонить по пути `properties.iconContent`. Не преобразовывать строку в число: исходное значение сохраняется. Это ограничение соответствует задаче нумерации, гарантирует один символ внутри кружка и не открывает исполнение произвольного HTML, которое допускает внешний конструктор. Альтернатива — принимать любой `iconContent` и выводить текстом — внесла бы неопределённые длинные подписи внутрь маленького маркера.
2. Добавить `iconContent` в `EditorialFeature`, mapper, `EditorialMapDataSchema`, `EditorialPublicGeometrySchema`, `toPublicEditorialGeometry` и `fromPublicEditorialGeometry`. Явные поля сохраняют границы ADR-013; добавление только в HTML-renderer оставило бы сборку неработающей и теряло бы данные публичной карты мест.
3. `createEditorialMapObjects` помещает значение через `textContent` в существующий DOM-кружок. Номер центрируется app-owned CSS, шрифт берётся из уже загружаемого семейства без нового начертания; подпись под точкой остаётся отдельным элементом, цвет фона — `marker-color`. Для ненумерованной точки никаких дополнительных видимых элементов не появляется. Использование готовых текстовых DOM-узлов проще и безопаснее HTML-шаблона или нового компонента.
4. В карте новости из `move.geojson` перенести только три поля `iconContent` к соответствующим точкам: остальные координаты, подписи, стили и ссылка уже совпадают с текущей вставкой. Исходник сохраняется в самой новости, временный `move.geojson` не становится опубликованным ресурсом.

## Risks / Trade-offs

- [Цифра в небольшом кружке может быть мелкой] → Проверить реальные значения `1`–`3` на десктопе и мобильном экране, не расширяя маркер и не добавляя шрифты ради этого материала.
- [Поле потеряется на одной из границ и карта не покажет номер либо публичная выдача его лишится] → Проверить raw→domain→HTML и raw→domain→public→map отдельными регрессиями, затем собрать сайт.
- [Разные авторские цвета маркера дают разную читаемость текста] → Проверить применённый синий цвет на этой карте; при расширении редакционного набора цветов отдельно пересмотреть контраст.
