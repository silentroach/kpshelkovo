## Настоящий SDK и браузер

Проверена локальная production-сборка в отдельной сессии agent-browser. Для настоящего SDK временный CDP-перехват в этой сессии отдавал HTML и assets локальной сборки на origin сайта и подключал существующий публичный SDK-скрипт опубликованной страницы. Запросы Яндекса и его реализация не подменялись; опубликованный сайт не менялся, ключ не записывался в репозиторий. Проверка сохраняла origin опубликованной страницы при локальном HTML и JS.

- Green Dreams при 1440 px: карта **481.828125×320 px**, координаты `x=804.171875`, `y=77` до и после правки.
- При 390 px: **318×240 px**, `x=36`, документный `y=596.53125`. При 320 px: **248×240 px**, `x=36`, документный `y=620.53125`. Горизонтального переполнения нет. Положение подписи проверено DOM-подстановкой; существующий тест страницы проверяет настоящий адрес вне статьи под картой.
- При 320 px штатный блок атрибуции полностью находится внутри карты и ниже кнопки Яндекса, пересечения нет. Проверен клавиатурный фокус ссылок атрибуции с видимым outline.
