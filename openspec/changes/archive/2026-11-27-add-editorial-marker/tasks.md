# Задачи

## 1. Редакторская разметка

- [x] 1.1 Подключить общее правило `==…==` в HTML и в разборе редакционных Markdown-фрагментов. Проверить на коротких примерах HTML-элемент, обычный `strong` в публичном `.md` и чистый текст для выдержки. Покрыть два выделения в абзаце, вложенную ссылку, код, экранирование, незакрытую пару и границу абзацев.
- [x] 1.2 Сверить фразу с `@slug` у закрывающей пары через обработчик упоминаний сайта: HTML и Markdown сохраняют ссылку на сущность и слова рядом с ней. Добавить авторский пример в [справочник Markdown](/packages/markdown/README.md).

## 2. Штрих и первая реплика

- [x] 2.1 Оформить редакционный маркер по `wide-nib.webp`, записать правило в [дизайн-гайд](/docs/design/design-code-shelkovo.md). В браузере сравнить штрих на одной и нескольких строках с эталоном, проверить короткий конец фразы на телефоне и контраст на фоне реплики, открытой по таймкоду.
- [x] 2.2 Использовать уже выделенную владельцем фразу из [транскрипции встречи с юристом](/apps/www/src/data/meetings/2026-03-20-tsn/transcript.yaml), не меняя транскрипцию. Сверить HTML и `.md` части: слова совпадают с исходными, таймкод ведёт к той же реплике, штрих и полужирный охватывают ровно выделенную фразу.

## 3. Приёмка

- [x] 3.1 Запустить `pnpm openspec:validate`, typecheck, затронутые тесты и сборку. Проверить, что тот же авторский пример вне транскрипции даёт маркер в HTML и полужирный в Markdown.
- [x] 3.2 Пройти [цикл ревью всего изменения](/docs/development.md#ревью-изменения-в-opencode) с учётом незакоммиченных файлов текущей ветки; исправить подтверждённые замечания и повторить затронутые проверки.

Владелец сам поставил маркер в реплике `00:27:00`. Текст выделения совпал в исходнике, HTML и `.md` после нормализации типографских пробелов HTML. Таймкод сохранился. Правило CSS ограничено классом редакторского маркера и не применяется к `<mark>` поисковых сниппетов.

Chrome: на 1440 и 390 px штрих выступает за край каждой строки и читается на зелёном фоне реплики, открытой по таймкоду. Отключение рисунка не изменило координаты строк; на 390 px горизонтальной прокрутки нет. Клик по маркеру оставляет хеш прежним. Короткое выделение на одной строке проверено в браузере без правки транскрипции. Печать и режим принудительных цветов отдельно не проверяли.
