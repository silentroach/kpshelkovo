# Proposal

## Why

Главная и сравнение посёлков загружают общий чанк с солнечными расчётами и расстояниями, хотя каждой странице нужна только одна из этих возможностей: [issue #846](https://github.com/silentroach/kpshelkovo/issues/846). При обсуждении владелец расширил задачу: явно описать побочные эффекты всех библиотек workspace и закрепить правило для будущих пакетов.

## What Changes

- Разнести солнечные функции и расчёт расстояний в отдельные модули `@shelkovo/geo`, сохранив существующие именованные импорты через корневой файл реэкспортов.
- Указать `sideEffects` во всех семи библиотеках `packages/*` по результатам проверки: `false` для вычислительных пакетов, списки исключений для CSS в `ui` и регистрации правил Typograf в `markdown`.
- Добавить в корневой `AGENTS.md` правило проверки import-time поведения при создании пакета или изменении его инициализации и импортов.
- Сравнить состав и размеры production-бандлов до/после, проверить независимую загрузку главной и сравнения, сохранить актуальные YAML-отчёты.
- Проверить сохранение типографики, стилей и шрифтов компонентов, включая отдельную страницу ошибки media-приложения.

## Capabilities

### New Capabilities

Нет. Изменение оптимизирует внутреннюю структуру библиотек и метаданные сборки; новых продуктовых возможностей или публичных API не добавляет.

### Modified Capabilities

Нет. Расчёты, интерфейсы, форматы данных, правила типографики и оформление сохраняются. Для этого технического рефакторинга указан `skip_specs: true`; способы реализации и разовая проверка загрузки остаются в `design.md` и `tasks.md`.

## Impact

- Изменяются `packages/geo/src`, манифесты `packages/{format,geo,ical,markdown,seo,ui,url}`, корневой `AGENTS.md` и отчёты `docs/bundle/`.
- Потребители в `apps/www` и `apps/media` сохраняют существующие пути импорта и проверяются на регрессии после изменения метаданных пакетов.
- Новые зависимости, дополнительные публичные входы пакетов и ручные правила разбиения чанков не требуются.
- Приёмка выполняется на локальных production-сборках и существующих тестах. Отдельная проверка на production не требуется; после выполнения приёмки PR закрывает #846.
