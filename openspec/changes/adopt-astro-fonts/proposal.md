# Proposal

## Why

Определения шрифтов, диапазоны символов и preload сейчас поддерживаются вручную в нескольких production- и тестовых подключениях, а системные fallback не подогнаны к метрикам веб-шрифтов. [Issue #907](https://github.com/silentroach/kpshelkovo/issues/907) переводит подключение на Astro Fonts API, чтобы упростить сопровождение и улучшить устойчивость текста при медленной загрузке, сохранив типографику и Font Budget.

## What Changes

- Подключить существующие Fira Sans 400/600 normal и PT Serif 700 normal через штатный `fontProviders.fontsource()` и `<Font>`.
- Использовать общие определения семейств для `apps/www`, `apps/media` и визуальных стендов; сохранить отдельный минимальный набор media 404.
- Передать генерацию `@font-face`, метрически подобранных fallback и URL для preload Astro; перевести потребителей на CSS-переменные и удалить заменённые ручные подключения.
- Сохранить загрузку шрифтов с origin страницы, WOFF2 и предзагрузку только критической кириллицы. `latin-ext` загружается по потребности текста.
- Проверить читаемость текста до загрузки и при отказе шрифтов, переносы, сдвиги, сетевые запросы и объём HTML/CSS/шрифтов на одинаковых условиях до и после изменения.
- Актуализировать проверку Font Budget и документацию подключения.

Выбор штатного Fontsource-провайдера уточняет первоначальное предпочтение локального провайдера в issue. В обсуждении выбран вариант с сетевой загрузкой при сборке и последующей самостоятельной раздачей файлов: установленный `local()` не передаёт метки subsets для выборочного preload, а собственный адаптер увеличивает стоимость сопровождения.

Редизайн, новые семейства, начертания и расширение Font Budget в объём изменения не входят.

## Capabilities

### New Capabilities

- `web-font-loading`: доставка шрифтов с origin страницы в пределах Font Budget, загрузка дополнительных алфавитов по потребности и читаемое отображение текста с метрически подобранным fallback.

### Modified Capabilities

Нет.

## Impact

- Конфигурации Astro обоих приложений; подключения в `BaseLayout.astro` и media 404; font tokens, `NotFoundView.astro`, exports и зависимости `@shelkovo/ui`.
- Визуальные стенды `apps/www` и `packages/ui`, существующий `font-budget.test.ts`, дизайн-гайд и документация пакета UI.
- При пустом font cache сборке нужны Fontsource API и CDN. Файлы провайдера не закрепляются npm lock-файлом; браузер получает готовые локальные assets. Существующий CI cache `node_modules/.astro` охватывает cacheDir обоих приложений.
- Проверка production-сборок, действующих asset-префиксов и CSP, typecheck, тесты, lint, анализ клиентских бандлов и браузерная приёмка до PR. Production-приёмка после merge не является условием завершения; после выполнения критериев PR закрывает #907.
