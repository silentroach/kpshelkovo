# Proposal

## Why

В работе над [#1186](https://github.com/silentroach/kpshelkovo/issues/1186) два подхода к Охотничьим прудам оказались мелкими в невысоком превью с большим запасом вокруг геометрии. Владелец попросил приблизить карту и добавить опциональное квадратное превью для отдельных мест.

## What Changes

- Редактор сможет выбрать квадратную область карты для отдельной карточки; обычные карточки сохранят нынешнюю высоту.
- Охотничьи пруды получат квадратное превью на широком и узком экранах.
- Превью с дополнительной геометрией будут вписывать её плотнее, сохраняя все объекты, основную точку и место для элементов Яндекса.
- В итог задачи войдут подготовленные подходы: менее заметные пунктирные линии, подписи «от дамбы» и «из Парка», описание обоих путей и приблизительности схемы в HTML и Markdown.
- Начало подхода из Парка и его изгибы будут уточнены по замечанию владельца: линия должна совпадать с видимым концом дороги и не образовывать лишнюю волну на подложке карточки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `place-card-presentation`: опциональное квадратное превью отдельного места с зарезервированным размером и адаптацией к ширине контейнера.

## Impact

- Raw-схема, доменная модель и mapper мест; серверный адаптер `PlacePreview.astro`; расчёт кадра общего превью.
- Данные Охотничьих прудов, редакционная инструкция карт и раздел карточки места в дизайн-гайде.
- Плотнее станут кадры карточек с дополнительной геометрией. Общая карта, Markdown-схемы и фоновые карты не получают новый способ вписывания.
- Форма превью относится к HTML-представлению; публичные JSON и Markdown не получают поле оформления. Новые зависимости и внешние сервисы не нужны.
- Приёмка локальная, с настоящим SDK на `localhost:4321`; отдельная production-приёмка не требуется. Изменение завершает #1186 в одном PR.
