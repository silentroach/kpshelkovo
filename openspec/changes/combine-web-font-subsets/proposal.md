# Proposal

## Why

На русскоязычных страницах латиница и кириллица нужны вместе, поэтому дробление каждого начертания создаёт дополнительные запросы и дублирует данные шрифта. Объединённые файлы позволяют снизить сетевой объём, сохранив знак рубля, который сейчас доступен только в `latin-ext`.

Связанный issue: [#1034](https://github.com/silentroach/kpshelkovo/issues/1034).

## What Changes

- Основной сайт получает один WOFF2 на начертание: Fira Sans 400/600 и PT Serif 700.
- Каждый файл содержит базовую латиницу, кириллицу и `₽`; отдельные `unicode-range` и загрузка полного `latin-ext` для сайта убираются.
- Сохраняются семейства, веса, роли текста, локальная доставка, `swap`, метрические fallback и отсутствие preload.
- Подготовка файлов воспроизводима, но не добавляет обработку шрифтов и внешние запросы в обычную сборку.
- Самостоятельная media-404 сохраняет существующее подключение.
- Обновляются проверки font faces, Font Budget и инструкция обновления локальных шрифтов.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `web-font-loading`: основной сайт доставляет единый набор символов на начертание, включая знак рубля, без отдельного расширенного набора.

## Impact

- Определения и проверка шрифтов в `/packages/ui`, тесты `/apps/www/src/lib/tests/font-budget.test.ts` и `/apps/www/src/lib/tests/font-data.test.ts`.
- Локальные подготовленные WOFF2, сведения об источнике и лицензиях, команда их воспроизведения.
- [Font Budget](/docs/design/design-code-shelkovo.md#font-budget) и [инструкция разработки](/docs/development.md).
- Новых runtime-зависимостей, внешних browser-origin и изменений CSP не требуется. Подготовка шрифтов может использовать отдельный редакторский инструмент; способ фиксируется в design.
- Символы вне целевого набора отображаются системным fallback вместо подключения полного `latin-ext`.
- Приёмка проводится локально на production-сборке; отдельная production-приёмка не требуется. После проверок, ревью и архива change PR закрывает issue.
