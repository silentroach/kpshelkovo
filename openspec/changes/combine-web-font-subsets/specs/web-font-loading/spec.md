# Spec Delta

## MODIFIED Requirements

### Requirement: Загрузка в пределах Font Budget

Страницы SHALL использовать семейства, начертания, формат файлов и предел базовой загрузки из [Font Budget](/docs/design/design-code-shelkovo.md#font-budget). Основной сайт SHALL доставлять базовую латиницу, кириллицу и `₽` одним файлом на начертание без дробления по `unicode-range` и отдельной загрузки `latin-ext`. Символы вне этого набора SHALL отображаться системным fallback. Страницы MUST NOT предзагружать веб-шрифты через preload.

#### Scenario: Подключение без font preload

- **WHEN** посетитель открывает страницу основного сайта или самостоятельную media 404
- **THEN** её HTML не содержит font preload, а нужные тексту веб-шрифты загружаются через CSS

#### Scenario: Текст в пределах базовых алфавитов

- **WHEN** видимый текст страницы основного сайта использует базовую латиницу и кириллицу
- **THEN** браузер загружает один объединённый файл на используемое начертание в пределах базового бюджета

#### Scenario: Знак рубля в тексте

- **WHEN** основной сайт отображает `₽` и файл нужного начертания загружен
- **THEN** знак отображается целевым веб-шрифтом из того же файла, без отдельного шрифтового запроса

#### Scenario: Расширенная латиница в тексте

- **WHEN** основной сайт отображает символы расширенной латиницы вне базового набора и знака рубля
- **THEN** они отображаются системным fallback без загрузки дополнительного файла `latin-ext`

#### Scenario: Облегчённая самостоятельная страница

- **WHEN** самостоятельная media 404 использует только часть начертаний и алфавитов общего Font Budget
- **THEN** она загружает только нужную ей часть и не предзагружает остальные файлы ради общего подключения
