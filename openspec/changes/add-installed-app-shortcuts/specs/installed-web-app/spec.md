## Purpose

Дать установленному сайту «Шелково Онлайн» единые параметры запуска и быстрые переходы к новостям, статусу сервисов и базе знаний через штатное меню браузера или ОС.

## ADDED Requirements

### Requirement: Общий manifest сайта

HTML-страницы сайта SHALL ссылаться через `link rel="manifest"` на один same-origin документ `/manifest.json`. Документ SHALL быть доступен без авторизации как корректный JSON с совместимым MIME-типом `application/json` или `application/manifest+json`.

#### Scenario: Обнаружение manifest из разных разделов

- **WHEN** браузер открывает главную, раздел или вложенную HTML-страницу сайта
- **THEN** в документе есть ровно одна ссылка `rel="manifest"` на `/manifest.json` текущего origin
- **THEN** переходы между страницами сохраняют ту же ссылку

#### Scenario: Получение manifest

- **WHEN** браузер запрашивает `/manifest.json`
- **THEN** сайт возвращает HTTP 200 и JSON manifest с совместимым MIME-типом

### Requirement: Единые параметры установленного приложения

Manifest SHALL объявлять `id: "/"`, `start_url: "/"`, `scope: "/"`, `display: "standalone"`, `lang: "ru"`, имя «Шелково Онлайн» и короткое имя «Шелково». Он SHALL использовать существующие PNG-иконки сайта размером 192×192 и 512×512 с назначением `any`, а для `theme_color` и `background_color` SHALL использовать действующий цвет темы сайта.

#### Scenario: Обычный запуск

- **WHEN** поддерживающий manifest браузер запускает приложение по обычному нажатию на иконку без shortcut URL
- **THEN** manifest задаёт открытие `/` текущего origin в режиме `standalone`
- **THEN** идентификатор и область приложения одинаковы независимо от страницы, с которой пользователь начал установку

#### Scenario: Имя и оформление приложения

- **WHEN** браузер читает метаданные установленного приложения
- **THEN** manifest содержит имена «Шелково Онлайн» и «Шелково» и язык `ru`
- **THEN** обе объявленные PNG-иконки доступны на том же origin, а их размеры соответствуют значениям `sizes`
- **THEN** цвет темы совпадает с `meta name="theme-color"` сайта и с цветом фона запуска в manifest

### Requirement: Приоритетные переходы к трём разделам

Manifest SHALL содержать ровно три элемента `shortcuts` в следующем порядке: «Новости» с `url: "/news/"`, «Статус» с `url: "/status/"`, «База знаний» с `url: "/kb/"`. Все целевые URL SHALL вести прямо на существующие HTML-страницы того же origin внутри `scope`, без промежуточной главной, параметров отслеживания и фрагментов.

#### Scenario: Состав и порядок меню

- **WHEN** браузер читает `shortcuts` из manifest
- **THEN** массив содержит три пары имени и URL в порядке «Новости», «Статус», «База знаний»
- **THEN** при ограничении меню первыми тремя элементами ни один из выбранных разделов не теряется

#### Scenario: Прямые адреса пунктов

- **WHEN** браузер следует по URL любого из трёх shortcuts
- **THEN** `/news/` возвращает страницу новостей, `/status/` возвращает страницу статуса сервисов, `/kb/` возвращает базу знаний
- **THEN** каждый ответ имеет HTTP 200 и HTML-содержимое без перенаправления на главную

### Requirement: Добровольная установка и браузерная совместимость

Возможность SHALL использовать штатную установку и manifest shortcuts браузера без собственного интерфейса предложения установки, регистрации service worker, офлайн-кеша или push. Обычный доступ к страницам SHALL сохраняться без установки приложения. Manifest SHALL использовать стандартные поля, поддерживаемые целевыми Chrome Android и Safari macOS; сайт SHALL не обещать одинаковый вид системного меню на разных платформах или поддержку manifest shortcuts на iOS.

#### Scenario: Посещение без установки

- **WHEN** пользователь открывает сайт как обычную веб-страницу
- **THEN** главная и целевые разделы доступны через существующую навигацию
- **THEN** новая возможность не показывает собственный баннер, диалог или кнопку установки и не регистрирует service worker

#### Scenario: Браузер не поддерживает shortcuts

- **WHEN** браузер не использует поле `shortcuts`
- **THEN** доступ к новостям, статусу и базе знаний через обычные URL сохраняется
- **THEN** сайт не подменяет системное меню собственным интерфейсом и не обещает работу этих переходов без сети
