# Проезды, которых не хватает в дорожном снимке

## Why

У трансформаторной подстанции к западу от Прилесной улицы есть щебневый проезд между двумя перекрёстками. На карте дорожного слоя здесь разрыв. Если дорисовать линию только на экране, для других потребителей дороги по-прежнему не будут соединены.

## What Changes

- Редактор хранит подтверждённые проезды отдельно от снимка OpenStreetMap. Сборка соединяет их с дорожной сетью по указанным узлам. Первое дополнение — перемычка со скриншота владельца.
- Если при обновлении OSM появляется тот же проезд или его часть, редактор показывает старый и новый варианты. Сократить или удалить локальную запись можно только после согласия владельца.

## Impact

Один из двух change для [#1390](https://github.com/silentroach/kpshelkovo/issues/1390) в общей ветке и PR. Затрагивает источники дорог, подготовку сети для карты и [порядок обновления](/docs/road-updates.md). Сеть можно собрать без сведений о покрытии. Расчёт покрытия описан в `mark-asphalt-road-areas`; построение маршрутов в задачу не входит.
