# Spec Delta

## ADDED Requirements

### Requirement: Публикация сравнения обходится без отдельного домена

Система SHALL публиковать сравнение тарифов на `kpshelkovo.online` по префиксу `/815/compare/`. Отдельный домен сравнения SHALL NOT входить в поддерживаемые хосты, в том числе для редиректов. Деплой SHALL NOT требовать для него DNS, сертификат, webroot или отдельную установку конфигурации. Актуальные инструкции и списки опубликованных адресов SHALL отражать этот состав хостов.

#### Scenario: Деплой без ресурсов отдельного домена сравнения

- **WHEN** сайт публикуется в окружении, где подготовлены только ресурсы действующих хостов
- **THEN** публикация сравнения не требует ресурсов отдельного домена и не устанавливает его обслуживание
- **AND** сравнение доступно на основном сайте по `/815/compare/`

#### Scenario: Адрес сравнения в информации о публикации

- **WHEN** оператор читает актуальные инструкции или список адресов результата деплоя
- **THEN** сравнение относится к основному сайту, а отдельный домен сравнения отсутствует среди обслуживаемых адресов
