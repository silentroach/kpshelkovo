# Spec Delta

## ADDED Requirements

### Requirement: Исходники мероприятий сгруппированы по месяцу начала

Редакторские Markdown-записи SHALL храниться в `apps/www/src/data/events/YYYY/MM/<event-id>.md`, где папки соответствуют московскому году и месяцу `starts_at`, а имя файла задаёт стабильный ID мероприятия, отдельный от публичного `slug`. При изменении месяца начала исходник SHALL перемещаться в соответствующую папку с сохранением ID и календарной идентичности. Публикационная проверка SHALL отклонять запись вне этой структуры, несовпадение папки с месяцем начала и несколько исходников одного стабильного ID.

#### Scenario: Поиск исходника по месяцу мероприятия

- **WHEN** редактор ищет мероприятие, начинающееся в мае
- **THEN** единственный исходник находится в папке мая соответствующего года, независимо от даты публикации связанной новости
- **THEN** многодневное мероприятие хранится только в месяце начала, без копий в папках последующих месяцев

#### Scenario: Перенос мероприятия в другой месяц

- **WHEN** редактор меняет начало с сентября на октябрь и перемещает исходник в октябрьскую папку, сохраняя имя файла
- **THEN** запись сохраняет свой стабильный ID, адрес самостоятельного ICS и UID
- **THEN** публичный адрес и ссылки из новостей следуют действующим правилам переноса мероприятия

#### Scenario: Папка расходится с датой

- **WHEN** исходник находится вне структуры года и месяца либо месяц папки не соответствует московскому началу мероприятия
- **THEN** публикационная проверка сообщает об ошибке с указанием исходника вместо пропуска записи или публикации противоречивых данных

#### Scenario: Исходник скопирован вместо переноса

- **WHEN** в разных месячных папках находятся два исходника с одинаковым стабильным ID
- **THEN** публикационная проверка отклоняет неоднозначную запись вместо перезаписи одной копии другой
