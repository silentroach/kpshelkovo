# Tasks

Работа начинается после явного согласования артефактов владельцем. `design.md` пропущен по условию `instructions design`: перенос существующего результата печати не меняет CSS, загрузку или способ рендера.

## 1. Контракт и владельцы документации

- [ ] 1.1 Подтвердить согласованный `content-print` чтением [print.css](/apps/www/src/styles/print.css), маршрутного охвата в [BaseLayout](/apps/www/src/layouts/BaseLayout.astro) и eager-вызовов в KB/news/галерее/архивных выжимках; выполнить существующую проверку `pnpm --filter @shelkovo/www exec vitest run src/lib/markdown/render.test.ts -t "loads printable images eagerly"`. Сверить полноту содержимого, скрытие UI, ссылки и разбиение с [результатами PR #728](https://github.com/silentroach/kpshelkovo/pull/728), а печать загруженных карт — с [site-maps](/openspec/specs/site-maps/spec.md); не объявлять чтение кода браузерной приёмкой.
- [ ] 1.2 Сократить [ADR-037](/docs/decisions/037-content-print-css.md) до причин штатной печати существующего DOM и eager-загрузки, согласовать [индекс](/docs/decisions/README.md) и ссылки. Проверить, что CSS-владение осталось у ADR-034/#791, карты — у `site-maps`, а исторические ограничения PR #728 и [снятая владельцем приёмка карт #819](https://github.com/silentroach/kpshelkovo/issues/819#issuecomment-5798818614) доступны по ссылкам и не названы успешными проверками. Для документационного переноса не добавлять браузерную матрицу, snapshots, smoke-обход или ожидание внешних ресурсов перед диалогом.
