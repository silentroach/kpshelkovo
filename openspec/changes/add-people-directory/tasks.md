# Задачи

## 1. Подборка

- [ ] 1.1 Добавить редакционный список из `design.md`, проверку данных и выборку профилей по slug. Описать рядом с профилями, как включить человека, переставить карточку и убрать её со страницы.
- [ ] 1.2 Проверить на небольших примерах редакционный порядок, исключённый профиль, неизвестную ссылку и повтор человека. Убедиться, что полный реестр не фильтруется и не пересортировывается.

## 2. Страница и навигация

- [ ] 2.1 Собрать статическую страницу `/people/` с заголовком, метаданными, ведущей персоной и адаптивной сеткой. Использовать реальные профили, штатную типографику, ссылки с клавиатурным фокусом и инициалы для людей без фото.
- [ ] 2.2 Связать хлебные крошки профилей со справочником в HTML и структурированных данных. Зарегистрировать вход в разделе `people`, согласовать discovery, проверить правила выдачи `/people/` и убрать устаревшие утверждения об отсутствии HTML-страницы.

## 3. Приёмка

- [ ] 3.1 Выполнить `pnpm openspec:validate`, typecheck, профильные тесты и сборку. Проверить доступность HTML и Markdown по их контрактам и присутствие исключённого из HTML человека в JSON, Markdown и по прямому адресу.
- [ ] 3.2 В браузере проверить широкий и узкий экран: порядок, верхнее выравнивание, длинные должности, инициалы, отсутствие горизонтальной прокрутки, переход по карточке с клавиатуры и возврат через «Люди».
- [ ] 3.3 Провести редакторское ревью видимых текстов и метаданных, затем ревью всего актуального diff по проектному циклу; исправить подтверждённые замечания и повторить затронутые проверки.
