# Spec Delta

## MODIFIED Requirements

### Requirement: Слой участков ненавязчиво различает сведения о продаже

Контуры и подписи SHALL отражать статус предложения: свободные и забронированные — общей лёгкой заливкой, недоступные — слабой серой с сероватым читаемым номером, проданные и без статуса — нейтрально. Данные SHALL передавать статус при наличии. Выбор SHALL иметь отдельный цвет и утолщённую обводку при любом статусе, различаясь не только непрозрачностью. Номер и подложка SHALL оставаться читаемыми; снятие выбора SHALL возвращать базовое оформление с учётом активного набора по `map-selection-sets`.

#### Scenario: Разные статусы рядом

- **WHEN** на включённом слое без подсветки набора соседствуют свободный, забронированный, недоступный, проданный участки и участок без статуса
- **THEN** свободный и забронированный имеют одинаковую лёгкую заливку, недоступный — слабую серую заливку и читаемый номер с сероватым оформлением, а проданный и участок без статуса не получают статусного выделения

#### Scenario: Выбор среди участков со сведениями о продаже

- **WHEN** пользователь выбирает свободный или забронированный участок среди соседних участков с такой же статусной заливкой
- **THEN** выбранный участок получает заливку отдельного цвета и более толстый отчётливый контур, а соседи сохраняют статусное оформление с учётом приглушения вне активного набора по `map-selection-sets`
- **AND** номер и детали подложки выбранного участка остаются читаемыми

#### Scenario: Выбор не зависит от статуса

- **WHEN** пользователь последовательно выбирает участки с разными статусами и участок без статуса
- **THEN** каждый из них получает одинаковое оформление выбора с усиленным контуром, различимым без распознавания оттенка заливки

#### Scenario: Снятие выбора на окрашенном участке

- **WHEN** пользователь выбирает участок со статусной заливкой вне активного набора и затем снимает выбор
- **THEN** отчётливое выделение сменяется статусным оформлением этого участка с приглушёнными границей и заливкой по `map-selection-sets`, а не нейтральным оформлением проданного

#### Scenario: Сведения для оформления публичного слоя

- **WHEN** публикуются геометрические данные карты для участков с известным статусом и без него
- **THEN** данные содержат сохранённый статус известного участка и не подставляют статус отсутствующему

#### Scenario: Выбор участника набора

- **WHEN** пользователь выбирает участника активного набора, а затем снимает одиночный выбор
- **THEN** одиночный выбор различим поверх подсветки набора; после его снятия сохраняется оформление участника набора независимо от статуса
