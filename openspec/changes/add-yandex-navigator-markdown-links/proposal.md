# Proposal

## Why

Водителям на Хеллоуине нужны ссылки из памятки на полные маршруты их групп в Яндекс Навигаторе. Владелец подтвердил открытие подготовленных ссылок и попросил отличать ссылки `yandexnavi:` собственным значком, как ссылки Telegram.

Задача: [#1200](https://github.com/silentroach/kpshelkovo/issues/1200).

## What Changes

- Добавить под двумя картами [памятки](/apps/www/src/data/kb/events/2026/halloween.md) уже проверенные владельцем ссылки на маршруты от места сбора до парка.
- Добавлять отдельный декоративный значок навигации к ссылкам со схемой `yandexnavi:` во всём редакционном HTML Markdown сайта.
- Сохранять адрес, подпись, вложенную разметку и доступность ссылки; публичный Markdown сохраняет обычную авторскую ссылку.
- Дополнить справочник Markdown и дизайн-гайд правилами нового значка.

## Capabilities

### New Capabilities

- `markdown-navigator-links`: единое оформление ссылок Яндекс Навигатора в редакционном Markdown и сохранение авторского назначения в HTML и companion.

### Modified Capabilities

Нет. Действующие правила Telegram-ссылок и карт сохраняются.

## Impact

- Обёртка Markdown в `apps/www/src/lib/markdown/`, её адресные тесты, общие стили сгенерированного контента и печати в `apps/www/src/styles/`.
- Две ссылки в существующем материале KB; координаты и порядок остановок берутся из уже подготовленных ссылок и сверяются с наборами карт.
- Новый значок работает в серверном HTML без клиентского JavaScript и внешних запросов. Зависимости не добавляются.
- Проверки выполняются до PR; отдельная приёмка после production-деплоя не требуется. Подтверждение владельцем открытия ссылок не считается проверкой всех остановок на обеих мобильных платформах.
