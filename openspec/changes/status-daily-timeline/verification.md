# Результаты проверок

## Согласованная предварительная проверка Chromium

- Владелец разрешил заменить предварительный прогон трёх браузеров проверкой через `agent-browser`. Safari не считается проверенным.
- В браузере Chromium 147, принадлежащем именованной сессии `agent-browser`, выполнено 7296 проверок через CDP: все центры, внутренние края и верх/низ области нажатия 24 px; четыре полосы 150/292 px (30 дней), 912/1132 px (90 дней); viewport 1024/1440 px; CSS zoom 1/1.25/2. Для выходящих за viewport ячеек использована прокрутка, точки не пропускались. Дополнительно проверены Home, End и обе стрелки.
- Ошибок выбора нет. Координатные поправки в продуктовый код не добавлены. Результат `chromium-result.json` и одноразовый скрипт `probe-chromium.mjs` лежат в каталоге исходного замера. Увеличение проверено через CSS zoom, не через пользовательское меню браузера.

## Предварительная проверка Firefox

- С разрешения владельца скачан Firefox 157.0, Playwright build 1555, в локальный кеш браузеров. Зависимости проекта не менялись.
- На сохранённом прототипе `range-probe.html` проверена 1991 точка: центры и внутренние края ячеек полос 150/292 px с 30 днями и 912/1132 px с 90 днями. Нативное значение совпало с индексом ячейки во всех проверенных точках.
- Прогон включал CSS `zoom` 1/1.25/2; точки за пределами viewport 1440 px пропускались. Это предварительная проверка, а не полная приёмка увеличения страницы, клавиш и работающей высоты. Результат и одноразовый скрипт сохранены рядом с исходными отчётами: `firefox-result.json`, `probe-firefox.mjs`.

## Блокировка предварительной проверки нативного выбора

- Safari 27.2 установлен; создание WebDriver-сессии через системный `safaridriver` завершилось ошибкой `session not created`: необходимо включить **Allow remote automation** в настройках Safari, раздел Developer.
- После включения владельцем remote automation ошибка о выключенной настройке исчезла. Два последующих создания Safari-сессии, включая попытку после `open -a Safari`, завершились таймаутом: `The session timed out while connecting to a Safari instance` / `Request creation of a new automation session`. Изменять настройки системы или закрывать пользовательские окна Safari агент не стал.
- Следующая диагностическая попытка также завершилась таймаутом. Системный журнал `com.apple.WebDriver.HTTPService` показывает доступность Safari для автоматизации (`Changed Automation Availability (Available)`), но ошибки доступа к графической среде процесса драйвера: `Failed to look up the port for "com.apple.windowserver.active"`, `This user is not allowed access to the window system right now`, а также недоступность TCC по XPC. Это подтверждённое ограничение текущего запуска драйвера; связь именно этих ошибок с таймаутом окончательно не установлена. Повторять одинаковое создание сессии без изменения среды нецелесообразно.
- Задача 1.2 не выполнена: прежняя примерка в Chromium не заменяет проверку всех ячеек, масштаба и клавиш в трёх браузерах. Продуктовый код не менялся; обход нативного выбора не добавлялся.
