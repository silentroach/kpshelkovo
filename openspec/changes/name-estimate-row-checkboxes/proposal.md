# Proposal

## Why

В [issue #173](https://github.com/silentroach/kpshelkovo/issues/173) чекбоксы калькулятора имеют одинаковое доступное имя «Включить позицию», а названия строк служат лишь описаниями. Скринридеру и голосовому управлению нужно имя по видимому названию соответствующей позиции.

## What Changes

- Использовать видимый заголовок строки как доступное имя нативного чекбокса, без общего префикса.
- Убрать повторение того же названия в доступном описании.
- Проверить реальные отрендеренные чекбоксы по роли и вычисленному имени, без фиксированного количества строк.
- Сохранить заголовки, начальное состояние, Tab/Space, серверную разметку без JavaScript и пересчёт при работающем JavaScript.
- Не менять расчёты, данные сметы, публичный JSON и загрузку клиентского кода.

## Capabilities

### New Capabilities

- `regulation-calculator`: доступность переключателей позиций калькулятора регламента.

### Modified Capabilities

Нет.

## Impact

- Только имя чекбокса в `/apps/www/src/pages/815/regulation/index.astro`, адресный тест доступности и согласование существующей controller-fixture с новым именем.
- Новых зависимостей, CSS, клиентских импортов и URL нет. Отдельная production-приёмка не требуется.
- Данные и тесты сопоставлений из #175, а также области #1012, #957 и #999 не затрагиваются.
