# Design

## Context

Мотивация — в [proposal](/openspec/changes/add-mobile-breadcrumb-up-arrow/proposal.md). Shared-компонент строит один SSR-список с полной microdata. До `64rem` скрыты главная и последний элемент, даже с `linkLast`; до `40rem` оставшиеся родители расположены вертикально. Первый видимый элемент не имеет разделителя.

## Goals / Non-Goals

**Goals:** определить единственный видимый ссылочный элемент без DOM-измерений и сохранить прочие режимы.

**Non-Goals:** менять сокращение пути, геометрию app-level полосы, брейкпоинты, ссылки, microdata, токены или клиентскую загрузку.

## Decisions

- На сервере определять элементы, остающиеся после нынешнего сокращения: не последний и не `href === '/'`. Кандидат на знак появляется, только если таких элементов ровно один и он имеет ссылку. Одна ссылка плюс видимая нессылочная подпись не удовлетворяют условию.
- Использовать отдельный `aria-hidden` знак `‹`, парный существующему `›`, с теми же локальными приёмами цвета, размера и отступа. Скрыть его по умолчанию и показывать только ниже `40rem`; текущие desktop-разделители сохраняются.
- Не применять History API, JS-подписки и измерения видимости: состав пути известен SSR, а ширину определяет CSS.
- По [ADR-034](/docs/decisions/034-native-css-architecture.md) знак принадлежит scoped CSS, полоса и фон — приложению. [ADR-033](/docs/decisions/033-integrated-tariff-comparison-section.md) сохраняет фактическую иерархию сравнения без искусственного уровня.
- Уточнить исключение в разделе крошек действующего [дизайн-гайда](/docs/design/design-code-shelkovo.md) и [README UI](/packages/ui/README.md), без переработки композиции.

## Risks / Trade-offs

- Ошибка подсчёта при `linkLast` или нессылочном элементе → расширить существующий визуальный стенд этими случаями.
- Изменение средней ширины или desktop → сохранить существующие проверки границ и desktop-эталоны.
- Длинная ссылка на узком экране → проверить выравнивание продолжения текста и увеличенный текст без переполнения.

## Ownership and Verification

- Исполнитель владеет `/packages/ui/src/Breadcrumbs.astro`, `/packages/ui/tests/breadcrumbs-visual/src/pages/index.astro`, `/packages/ui/tests/breadcrumbs.visual.local.spec.ts`, README UI и только разделом крошек дизайн-гайда.
- Не менять routes, app-level стили, compare-controls browser suite и файлы остальных четырёх задач.
- Визуальная команда стенда использует отдельный порт `4325`; браузерные проверки собранного сайта координирует оркестратор без `pnpm dev`.
- Контрольные поверхности: место, человек, услуги регламента, рейтинг сравнения, отзыв с `linkLast`; несколько родителей — новость, мероприятие и вложенная KB; пустой путь — корни разделов. Печать сохраняет скрытую навигацию.
- Приёмка: existing visual suite, related breadcrumb tests, typecheck, сборка, валидация OpenSpec и reviewer всего diff. Обычный деплой; откат возвращает change целиком.
