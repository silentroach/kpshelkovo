# Задачи

## 1. Обновление снимка

- [ ] 1.1 Добавить команду получения дорожной выгрузки и приёма сохранённого файла. Проверить на небольшом примере отбор автомобильных линий, сохранение порядка и общих ID узлов, приём разрыва и отказ без замены снимка при ошибке сети или отсутствующем узле.
- [ ] 1.2 Добавить сравнение кандидата с принятой версией. Проверить добавление и удаление дороги, сдвиг общего узла без изменения версии `way`, замену ссылки при неизменных координатах и пустой diff при повторе.
- [ ] 1.3 Получить первый снимок с источником, датой, охватом и ODbL; проверить четыре части, подъезды и связи между ними. На одном участке сети разобрать тупик, параллельные улицы и путь от КПП по общим узлам. Описать обнаруженные разрывы и границу выгрузки в PR, не дорисовывать сеть.
- [ ] 1.4 Описать команды, чтение отчёта, приём, лицензию и откат через Git в руководстве по обновлению дорог. Повторить документированные шаги с тем же файлом: без обращения к OSM и без нового diff.

## 2. Линии на общей карте

- [ ] 2.1 Подготовить из снимка компактные линии и независимую настройку смещения. Проверить нулевую и ненулевую поправки, повторную сборку, точность координат и неизменность исходной сети и участков.
- [ ] 2.2 Подключить линии и атрибуцию к состоянию «Инфраструктуры». Проверить обычное открытие, `/map/?l=infra`, ручное выключение при незавершённой загрузке и доступность остальных объектов при ошибке дорожного ресурса.
- [ ] 2.3 Сверить в браузере линии на подложке, отсутствие реакции дороги на нажатие и выбор участка под линией. Показать владельцу первый охват целиком и крупный план перекрёстка; по его замечаниям уточнить охват.

## 3. Приёмка

- [ ] 3.1 Выполнить `pnpm openspec:validate`, typecheck, затронутые тесты и сборку; сравнить состав и размер клиентских ресурсов по [инструкции](/docs/development.md#анализ-клиентских-бандлов). Убедиться, что выключенный слой не загружает снимок и браузер не запрашивает данные у OSM.
- [ ] 3.2 Пройти [ревью всего diff](/docs/development.md#ревью-изменения-в-opencode), разобрать замечания и повторно проверить исправления.
