# Spec Delta

## MODIFIED Requirements

### Requirement: Подготовленные данные карт проверяются до публикации

Система SHALL проверять конечный payload редакционной карты в HTML, публичную геометрию мест в `/map/data/places.json` и каждый файл данных частей слоя участков после подготовки координат и свойств, до сериализации. Несоответствие контракту соответствующего представления SHALL останавливать сборку до публикации.

Браузер SHALL использовать эти артефакты собственной сборки без повторной схемной проверки и загрузки её исполняемого кода, сохраняя предусмотренные преобразования между публичным и отображаемым представлениями. Отдельная загрузка JSON SHALL NOT сама по себе требовать повторной проверки уже подготовленных данных. Обнаруженные ошибки доставки, разбора и применения данных SHALL сохранять предусмотренные для соответствующей карты сообщение и восстановление.

#### Scenario: Ошибка в конечном представлении

- **WHEN** исходная геометрия прошла входную проверку, но подготовка конечного представления создала недопустимые данные
- **THEN** сборка завершается ошибкой до их сериализации и публикации, не откладывая обнаружение нарушения до открытия карты читателем

#### Scenario: Редакционная карта из HTML

- **WHEN** читатель открывает материал с подготовленной редакционной картой
- **THEN** браузер использует проверенные при сборке данные из HTML для показа схемы без загрузки кода повторной схемной проверки

#### Scenario: Геометрия мест из статического JSON

- **WHEN** общая карта получает собственный статический JSON с дополнительной геометрией мест
- **THEN** браузер переводит проверенную публичную геометрию в отображаемое представление без загрузки кода повторной схемной проверки

#### Scenario: Отложенное включение участков

- **WHEN** пользователь включает части слоя участков или открывает прямую ссылку на участок
- **THEN** браузер загружает подготовленные данные нужных частей, а это действие не подключает код повторной схемной проверки
- **AND** отображаемые контуры и подписи используют проверенные при сборке координаты

#### Scenario: Недопустимые данные одной части

- **WHEN** конечное представление одной части участков нарушает свой контракт, а остальные части корректны
- **THEN** сборка останавливается до публикации вместо выпуска неполного набора частей
