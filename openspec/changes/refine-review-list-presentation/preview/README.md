# Выбранный вариант Г

Галерея сохранённых снимков списка отзывов. Слева исходный production, справа вариант Г: заголовок, автор, дословный фрагмент обычным текстом, компактные оценки.

Из корня workspace:

```bash
python3 -m http.server 4360 --bind 127.0.0.1 --directory openspec/changes/refine-review-list-presentation/preview
```

Открыть `http://127.0.0.1:4360/`. Можно выбрать всю страницу или отдельный отзыв, ширины 1440, 390 и 320 px. Нажатие на изображение открывает снимок в полном размере. При занятом порте сначала проверить, какой процесс его использует.

## Состав

- `index.html`, `gallery.css`, `gallery.js`: локальный просмотр статических изображений.
- `images/*-before.webp`, `*-after.webp`, `*-pair.webp`: исходный вид, выбранная примерка и парное сравнение.
- `quotes.json`: выбранные фрагменты для переноса в frontmatter при реализации; это снимок решения, не production-источник данных.
- `checks.json`: время съёмки, размеры и результаты сверки содержимого для трёх ширин.

Снимки сделаны через `agent-browser` временными DOM/CSS-правками production-страницы. Они не содержат работающего прототипа ссылок и меню. История выбора и границы проверки описаны в [comparison](/openspec/changes/refine-review-list-presentation/comparison.md); реализацию определяет [design](/openspec/changes/refine-review-list-presentation/design.md).
