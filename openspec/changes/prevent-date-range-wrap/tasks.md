# Tasks

В обсуждении выбраны HTML-обёртка диапазонов в правиле Typograf и включение только `ru/optalign/quote`. По указанию владельца от 7 октября 2026 года текущая сессия публикует только план в PR для чтения и ревью. Реализация продолжится отдельной сессией в той же ветке `fix/958-unbreakable-date-ranges`; перед началом подтвердить разрешение на реализацию актуальных артефактов. До выполнения задач change остаётся активным.

## 1. Общие правила и контракты вывода

- [ ] 1.1 Реализовать обёртку диапазонов внутри Typograf, включить `ru/optalign/quote` для HTML-режима и разделить текстовый, безопасный текстовый HTML- и готовый HTML-входы. Описать контракты в README пакета. Адресными тестами проверить дефис и тире, месяцы и границы совпадений, отсутствие WORD JOINER, экранирование буквальных тегов и entities, сохранность атрибутов и кода, совместную и повторную обработку правил; подтвердить, что bracket/comma не включены. Выполнить тесты и typecheck пакета.
- [ ] 1.2 Адаптировать rehype и Satteri к созданным Typograf HTML-узлам через общий безопасный адаптер; сохранить пробелы на границах, вложенное оформление и защищённые элементы, пропускать уже созданные типографические обёртки. Проверить одинаковое поведение обоих путей, целиком выделенный или помещённый в ссылку период, буквальную разметку и два последовательных AST-прохода без вложенных обёрток. Выполнить `pnpm --filter @shelkovo/markdown test` и `pnpm --filter @shelkovo/markdown typecheck`.
