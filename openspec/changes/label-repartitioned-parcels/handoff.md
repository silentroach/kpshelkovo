## Решения из разговора

Владелец просил простое решение без «мегакомбайна». Обычные объединения и раздел одного обозначения его устраивают. Для случая «несколько → несколько» достаточно общего ориентира: нынешние межи сохраняются, одна подпись перечисляет старые номера через `/`, вся группа выделяется вместе, поиск любого старого номера приводит к ней. Слеш отличает непоследовательную пару `F53/F56` от диапазона.

После просмотра четырёх PNG владелец ответил:

> 1 - как будто 3 объединили и потом перераспределили, наверное надо как-то обрабатывать, как наш кейс с превращением из 2 в 3 участка
>
> 2 - давай посчитаем что на генплан метку просто не нанесли и сделаем А64 связанным по границам с картами
>
> 3 - давай свяжем по твоему предположению
>
> 4 - тут прям наложение нормас, давай закрепим по визуальному соответствию, тут очевидно все

Это решения для V1/V2/V19, A64, V30 и A1/A2 соответственно; точные связи, площади, параметры привязки и порядок исправления A2 — в разделе «Связи, принятые владельцем по новым наложениям» и последующих разделах [design](/openspec/changes/label-repartitioned-parcels/design.md). Восемь первоначальных пар «два → три» остаются кандидатами для адресной проверки из этого же документа.
