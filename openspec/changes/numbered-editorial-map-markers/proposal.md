# Proposal

## Why

Обновлённая схема объезда содержит номера точек в `properties.iconContent`, но строгая проверка геоданных отклоняет это поле: редактор не может показать порядок движения на карте статьи. Нужно принимать однозначные цифровые метки из экспорта Конструктора Яндекса и показывать их внутри существующих маркеров без ручной переделки геометрии.

## What Changes

- Поддержать односимвольные цифровые строки `iconContent` у точек в общем редакционном GeoJSON для блоков `map` и дополнительной геометрии мест; сохранить их в публичной геометрии мест.
- Показывать номер внутри стандартного кружка точки, оставив подпись `iconCaption` рядом с ней и обычные ненумерованные точки без изменений.
- Обновить GeoJSON схемы объезда в новости `alternative-access.md` из предоставленного `move.geojson`: номера `1`, `2`, `3` соответствуют Семеновскому, съезду в Авдотьино и воротам.
- Дополнить редакционную инструкцию по картам примером и описанием числовой метки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `map-geodata`: однозначный цифровой `iconContent` принимается, сохраняется в геоданных и показывается внутри маркера точки без интерпретации как разметки.

## Impact

- Затронуты схемы и адаптеры `apps/www/src/lib/geometry`, HTML-граница и отрисовка `apps/www/src/components/maps`, публичный JSON геометрии мест, статья `apps/www/src/data/news/articles/2026/09/alternative-access.md` и `docs/editorial-maps.md`.
- Внешний формат `properties.iconContent` расширяется обратно совместимым образом; новых зависимостей и изменений API Яндекс Карт нет.
- Связанный issue: [#831 — Показать цифры внутри маркеров редакционных карт](https://github.com/silentroach/kpshelkovo/issues/831).
