# Proposal

## Why

При нулевой выдаче поиск сообщает только «Ничего не нашли», и человеку приходится самому решать, как изменить запрос. В [#1229](https://github.com/silentroach/kpshelkovo/issues/1229) согласована короткая подсказка с дополнительным советом для длинного запроса.

## What Changes

- После успешного поиска без результатов показывать «Ничего не нашли. Попробуйте другие слова».
- Для запроса длиннее 30 символов показывать «Ничего не нашли. Попробуйте другие слова или сократите запрос».
- При подсчёте длины исключать пробелы по краям, учитывать внутренние пробелы. Подсказка относится к текущему запросу и доступна визуально и через существующее объявление состояния поиска.
- Объём ограничен текстом пустой выдачи общего поиска сайта. Качество фрагментов вынесено в [#1254](https://github.com/silentroach/kpshelkovo/issues/1254), автоматические предложения запросов в [#1255](https://github.com/silentroach/kpshelkovo/issues/1255), поиск разделов в [#1256](https://github.com/silentroach/kpshelkovo/issues/1256).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `search`: текстовая помощь при нулевой выдаче с условным советом сократить длинный запрос.

## Impact

- [SearchDialog.svelte](/apps/www/src/components/search/SearchDialog.svelte): вычисление сообщения и его вывод в существующем состоянии `empty`.
- [SearchDialog.test.ts](/apps/www/src/components/search/tests/SearchDialog.test.ts): существующие проверки состояний и клавиатуры используются для контроля регрессий; новый порог проверяется адресным браузерным сценарием.
- Приёмка до PR: проверки компонента, типов и production-сборки с браузерным сценарием; редакторское и техническое ревью. Отдельная приёмка после публикации не требуется.
