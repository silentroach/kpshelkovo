# Примерка профилей людей

Зафиксированные сравнения production и предложенного оформления от 19 октября 2026 года. Галерея работает с локальными WebP-снимками.

Из корня репозитория:

```bash
python3 -m http.server 4363 --bind 127.0.0.1 --directory openspec/changes/refine-people-presentation/preview
```

Открыть `http://127.0.0.1:4363/`. В списках доступны пять профилей и три ширины. Справа показаны проверенная единственная должность Юрия и бывшая роль Сергея Минакова в описании. У Сергея нет подзаголовка с текущей должностью и секции контактов. [Описание предложений и результаты](/openspec/changes/refine-people-presentation/comparison.md).

## Файлы

- `images/*-pair.webp`: парные сравнения, слева текущий вид, справа предложение.
- `images/*-before.webp`, `images/*-after.webp`: отдельные половины без масштабирования.
- `index.html`, `gallery.css`, `gallery.js`: оболочка просмотра сохранённых снимков.
- `proposal.css`: стили кандидата, ограниченные корнем временной примерки.
- `apply.js`: временная перестановка DOM, скрытие пустой секции контактов, уточнение должности Юрия и перенос бывшей роли Сергея в описание. Разбор готовой строки по запятой применим только к этим известным образцам; production должен читать отдельные поля профиля.
- `capture.mjs`: съёмка через отдельную сессию `agent-browser`, адресные проверки и сборка парных WebP с установленным в `apps/www` Sharp. Для просмотра галереи зависимости не нужны.
- `checks.json`: результаты съёмки с измерениями и отметками сохранности содержимого.

## Повторная съёмка

```bash
node openspec/changes/refine-people-presentation/preview/capture.mjs
```

Команда заново открывает production, применяет временную примерку и перезаписывает снимки и отчёт. При изменившемся production это будет новое сравнение; сохранённые изображения фиксируют состояние на дату съёмки. Перед повтором проверь актуальность CSS-селекторов, примеров и записей в [comparison](/openspec/changes/refine-people-presentation/comparison.md).

Для адресной пересъёмки передай slug, например `node openspec/changes/refine-people-presentation/preview/capture.mjs sminakov ykizilov`. Остальные снимки и их записи отчёта сохраняются. В отчёте указано время каждой съёмки.

Галерея показывает статические изображения: ссылки и меню внутри изображений не интерактивны. Проверка будущего HTML, работы без JavaScript, источников, контраста и фокуса перечислена в [tasks](/openspec/changes/refine-people-presentation/tasks.md).
