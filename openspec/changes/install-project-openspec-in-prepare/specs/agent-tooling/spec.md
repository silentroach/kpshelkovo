# Spec Delta

## MODIFIED Requirements

### Requirement: Штатная интеграция с независимыми параметрами

Обычный `pnpm install` в проекте SHALL восстанавливать штатную интеграцию OpenCode из закреплённой версии OpenSpec со схемой `spec-driven`, независимо от глобального профиля. Git SHALL игнорировать установленные скиллы OpenSpec и их служебную регистрацию; проектные дополнения остаются в конфигурации и правилах. Вызовы CLI SHALL следовать [правилу запуска](/AGENTS.md#выбор-маршрута), включая upstream-примеры.

#### Scenario: Установка в отдельном ворктри

- **WHEN** участник устанавливает зависимости в новом ворктри
- **THEN** базовые скиллы OpenSpec доступны в этом ворктри, а рабочее дерево остаётся чистым
- **AND** установочные скрипты сторонних зависимостей не выполняются

#### Scenario: Повторная установка

- **WHEN** участник повторяет установку с актуальным набором скиллов
- **THEN** для скиллов не требуется повторное скачивание
- **AND** если скилл удалён, следующая установка восстанавливает его из закреплённого релиза

#### Scenario: Другой глобальный профиль

- **WHEN** участник повторяет установку с другим глобальным профилем OpenSpec
- **THEN** результат побайтно совпадает с установкой при чистом профиле, а личный профиль не изменяется

#### Scenario: Форматирование перед коммитом

- **WHEN** formatter или commit hook обрабатывает изменённые файлы
- **THEN** скиллы OpenSpec сохраняют штатное содержимое
