# Tasks

## 1. pnpm и хуки установки

- [ ] 1.1 Закрепить pnpm 12.23.0 и обновить lock-файл. Сверить diff на посторонние обновления и проверить `pnpm --version` и `pnpm install --frozen-lockfile`.
- [ ] 1.2 Разрешить проектные хуки, запретить установочные скрипты зависимостей и обеспечить повторный вызов `prepare`. Проверить на чистой установке и повторе: Git использует `.githooks`, сторонние скрипты не запустились.

## 2. Проектная интеграция OpenSpec

- [ ] 2.1 Перенести штатную установку OpenSpec в ворктри согласно [design.md](/openspec/changes/install-project-openspec-in-prepare/design.md), подключить через `prepare` и убрать дублирование из `agents:setup`. Проверить, что ошибка или неполная установка прерывает команду.
- [ ] 2.2 Убрать из индекса штатные скиллы и маркер, обновить `.gitignore`, конфигурацию OpenSpec и инструкции по установке, обновлению и откату. Сверить `git ls-files` и `git check-ignore`; собственные скиллы по-прежнему отслеживаются.
- [ ] 2.3 Адаптировать тесты и CI. На `pnpm test:agent-tooling` проверить изоляцию профиля, готовый набор при повторной установке, восстановление пропавшего скилла и обнаружение неполного набора или дублей.

## 3. Приёмка

- [ ] 3.1 В чистой рабочей копии запустить `pnpm agents:setup` и `pnpm skills:check`. Проверить чистый `git status`, включая новые файлы. На новом pnpm выполнить линтер, typecheck, тесты и сборку проекта.
- [ ] 3.2 Выполнить `pnpm openspec:validate` и пройти [ревью полного diff](/docs/development.md#ревью-изменения-в-opencode) по требованиям change.
