# Задачи

## 1. Сборка данных

- [ ] 1.1 Подготовить `base`, `infra` и `club` из тех же проверенных источников, что у публичной карты. Проверить разделение мест с дополнительной геометрией, отсутствие скрытых мест в файлах и индексе, полноту прежнего `/map/data/places.json`.
- [ ] 1.2 Включить линии и источник OSM в файл инфраструктуры вместо дорожного ресурса. На той же сборке сравнить линии с результатом прежнего адаптера, убедиться, что остальная карта их не получает.

## 2. Загрузка на карте

- [ ] 2.1 Переключить старт карты на базовый файл. Для обоих переключателей проверить первый запрос, повторное включение без дублирования, поздний ответ, отказ одного слоя и успешную повторную попытку. Проверить выбор участка под дорогой и появление атрибуции только вместе с линиями.
- [ ] 2.2 Разрешать цели `h` и места из `set` через базовый индекс. Проверить фокус для обоих слоёв, неизвестную и подавленную через `p` цель, `l` вместе с набором, запрос одного слоя сразу по двум основаниям. Проверить приоритет камеры и отмену её перемещения при ручном выключении.

## 3. Приёмка

- [ ] 3.1 В браузере сравнить запросы при обычном входе, включении каждого слоя, прямой ссылке и смешанном наборе. Сверить ручное вписывание клуба с начальным `l=club`. Сравнить размеры стартовой загрузки и файлов при включении, обновить отчёты бандлов по [инструкции](/docs/development.md#анализ-клиентских-бандлов).
- [ ] 3.2 Проверить OpenSpec, типы, затронутые тесты и production-сборку. Пройти [ревью актуального diff](/docs/development.md#ревью-изменения-в-opencode), разобрать замечания и проверить исправления.
