# Загрузка инфраструктуры и клубных мест по слоям

## Why

При обычном открытии карта загружает маркеры и геометрию выключенных слоёв. Инфраструктура при этом разделена между общим справочником и отдельным файлом дорог. В [задаче #1391](https://github.com/silentroach/kpshelkovo/issues/1391) хотим привязать загрузку к выбору жителя: один включённый слой — один файл.

## What Changes

- При обычном открытии получать только данные обычных мест. Загружать `infra` и `club` независимо, при первом включении вручную или по ссылке.
- Собирать в `infra` инфраструктурные места с их геометрией и готовые линии дорог, в `club` — клубные места с их геометрией.
- Оставить `/map/data/places.json` полным публичным справочником в прежнем формате. При обычном открытии интерактивная карта его не запрашивает.

## Impact

Затронуты сборка внутренних JSON карты, загрузка и переключение слоёв в `PlaceMap`, тесты прямых ссылок и именованных наборов. Состав мест, контур дорог и оформление карты остаются прежними. Работа продолжает [PR #1389](https://github.com/silentroach/kpshelkovo/pull/1389).
