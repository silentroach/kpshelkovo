# Spec Delta

## MODIFIED Requirements

### Requirement: Ссылка задаёт дополнительные начальные слои

Общая карта SHALL принимать параметр `l` со списком через запятую: `infra` включает инфраструктуру, `club` включает клубные места, `shf`, `shv`, `shp`, `shr` включают соответствующие части участков, `parcels` включает все части. Запрошенные слои SHALL дополнять обычное начальное состояние одинаково на узком и широком экране. Без распознанных значений SHALL сохраняться обычное открытие.

#### Scenario: Несколько слоёв

- **WHEN** карта открыта по `/map/?l=infra,shf`
- **THEN** инфраструктура и участки Фореста включены, обычные места видны, остальные части не включаются из-за `l`
- **AND** переключатели показывают фактическое состояние слоёв

#### Scenario: Все участки

- **WHEN** карта открыта по `/map/?l=parcels,infra`
- **THEN** все части участков и инфраструктура включены

#### Scenario: Параметр отсутствует

- **WHEN** карта открыта без `l` и без прямых целей
- **THEN** сохраняется обычный начальный набор слоёв

#### Scenario: Только клубные места

- **WHEN** карта открыта по `/map/?l=club` без прямых целей
- **THEN** клубные места включены, инфраструктура и участки не включаются из-за `l`
- **AND** начальный кадр совпадает с обычным открытием по общему правилу камеры для `l`

#### Scenario: Клубные места вместе с другими слоями

- **WHEN** карта открыта по `/map/?l=club,infra,shf`
- **THEN** включены клубные места, инфраструктура и участки Фореста
- **AND** переключатели отражают их состояние, а последующее ручное переключение и прямые цели следуют общим правилам `map-layer-links`
