# Proposal

## Why

В калькуляторе регламента объяснение «нет единой базы» обрезается справа на мобильном экране. Читатель не может полностью прочитать причину отсутствия расчётного значения. Задача: [#150](https://github.com/silentroach/kpshelkovo/issues/150).

## What Changes

- Объяснения отсутствующих значений помещаются в видимую область таблицы на узком экране, а текст переносится.
- Сохраняются клавиатурное и сенсорное раскрытие, связь объяснения с кнопкой и работа без JavaScript.
- Не меняются горизонтальная прокрутка таблицы, расчёт тарифа и общие стили сайта; новый универсальный tooltip-компонент не добавляется.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `regulation-calculator`: читаемость объяснений отсутствующих значений и сохранение доступного раскрытия.

## Impact

- Локальная разметка и CSS `/apps/www/src/pages/815/regulation/index.astro`, адресные проверки калькулятора.
- Основная приёмка — браузерная проверка реальной страницы на узком экране, с прокруткой таблицы и клавиатурой; DOM-тест не доказывает отсутствие обрезания.
- Новые зависимости, общий UI-примитив и отдельная production-приёмка не нужны. После локальной приёмки PR закрывает #150.
