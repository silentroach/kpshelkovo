# Proposal

## Why

В карточке места адрес под картой выглядит отдельной строкой, хотя в новостях подписи визуально связаны с изображением. Нужно сделать адрес частью единого географического блока на узких и широких экранах, не меняя сведения о месте и переходы к картам. Задача: [#867](https://github.com/silentroach/kpshelkovo/issues/867).

## What Changes

- Оформить адрес карточки места по существующему паттерну подписи к медиа в новостях.
- Сохранить текущую разметку смыслового блока, данные адреса, внешний переход с маркера и штатное действие карты; карточка без адреса остаётся без подписи.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `place-card-presentation`: адрес при наличии воспринимается как подпись к карте и остаётся визуально связанным с ней на узких и широких экранах.

## Impact

- Локальное оформление `apps/www/src/pages/map/[slug]/index.astro` с использованием существующего стиля `ui-media-caption`; без изменения данных, клиентского кода, API и зависимостей.
- Проверка результата на узком и широком экранах; отдельная production-приёмка не требуется.
