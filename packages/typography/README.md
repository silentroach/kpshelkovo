# @shelkovo/typography

Общая строковая типографика на базе Typograf для клиента и сервера. Пакет владеет единым набором правил для обычного текста, HTML-фрагментов и Markdown-адаптеров.

## Импорт и граница пакета

```js
import { formatText, formatTextHtml, formatDynamicHtml } from '@shelkovo/typography';
```

Корневой вход client-safe: напрямую загружает строковое ядро и Typograf, без Markdown, Satteri, HTML-парсера, нативных модулей и данных приложения. Регистрация правил выполняется в единственном модуле ядра при импорте; `sideEffects` пакета сохраняет её при tree-shaking.

[Markdown-пакет](/packages/markdown/README.md) зависит от типографики и владеет `rehypeTypograf`/`satteriTypograf` и обходом AST. Обратной зависимости нет. Приложение выбирает место применения типографики; общие правила и их регистрация меняются в `@shelkovo/typography`.

## Публичный API и безопасность

- `formatText(text)`
  Обычный текст → типографированный текст без сгенерированных тегов. Для атрибутов, доступных подписей, `textContent` и сравнения редакций. HTML-правила отключены через `ruleFilter`; буквальные теги и записи entities остаются текстом. Результат вставляется как текст, с обычным экранированием шаблона или через `textContent`; это не экранированный HTML.

- `formatTextHtml(text)`
  Обычный текст → безопасный HTML для коротких строк в шаблонах (`set:html`). Исходные `<`, `>` и `&` экранируются; элементами становятся только обёртки типографа. Например, буквальное `<em>` остаётся видимым текстом, а `&copy;` не превращается в ©. Результат при повторном HTML-проходе передаётся в `formatDynamicHtml`, поскольку `formatTextHtml` всегда считает вход обычным текстом.

- `formatDynamicHtml(html)`
  Подготовленный HTML-фрагмент → типографированный HTML с сохранением элементов и атрибутов. Безопасность исходной разметки обеспечивает вызывающий код; эта функция не санитизирует HTML. Код и другие защищённые элементы сохраняются дословно.

Корневой вход также экспортирует общие определения ядра для AST-адаптеров:

- `TYPOGRAPHY_SKIP_TAGS` — набор защищённых элементов, содержимое которых типографика пропускает.
- `TYPOGRAPHY_WRAPPER_CLASSES` — набор классов обёрток типографа для распознавания уже обработанной разметки.

## Общие правила и HTML/CSS-контракт

Все строковые API и Markdown-адаптеры используют один набор правил Typograf. В HTML-выводе диапазон дней с общим полным русским месяцем получает `<span class="nowrap-date-range">`; год остаётся снаружи. Исходный дефис и короткое тире дают одинаковый результат с коротким тире. В текстовом выводе сохраняется обычная типографика без сгенерированных тегов. Дополнительных управляющих символов в копируемом тексте нет.

Кавычки проходят обычное типографическое преобразование без оптического выравнивания и дополнительных обёрток. Ссылки, выделение и защищённый код сохраняются; правило `common/punctuation/quoteLink` отключено, чтобы кавычки оставались внутри авторской ссылки и в HTML-, и в AST-пути. Повторный HTML- или AST-проход не вкладывает обёртки диапазонов друг в друга.

CSS принадлежит приложению по [ADR-034](/docs/decisions/034-native-css-architecture.md). Пакет выдаёт semantic hooks и не поставляет stylesheet. В `apps/www` правила находятся в [global.css](/apps/www/src/styles/global.css), в слое `content` под `.site-page-content`, чтобы работать и для коротких строк вне `.ui-prose`:

- `.nowrap-date-range` — `white-space: nowrap`.

Выбор пакетов и направления зависимости обоснован в [ADR-003](/docs/decisions/003-markdown-pipeline-layering.md); места применения на сайте задают [инструкции приложения](/apps/www/AGENTS.md#типографика).
