# @shelkovo/ical

Private workspace-пакет без runtime-зависимостей. `renderEventIcs(event: CalendarEvent)` возвращает строку UTF-8 iCalendar с одним событием, CRLF и переносами не длиннее 75 байт.

Вызывающий код передаёт готовые `uid`, `prodId`, `timestamp`, `startsAt`, `endsAt`, `title`, `description`, `url` и необязательное `location` (`name`, `address?`, `latitude`, `longitude`). Типы `CalendarEvent` и `CalendarLocation` экспортируются из пакета. Данные должны пройти валидацию до вызова; невалидная дата вызывает ошибку. Сериализатор не выбирает даты и длительность по умолчанию.

## Проверки и обновление эталонов

Из корня workspace:

```bash
pnpm --filter @shelkovo/ical typecheck
pnpm --filter @shelkovo/ical exec vitest run src/index.test.ts --update=none
```

Тест сравнивает свежую генерацию с четырьмя `.ics` ниже. Несовпадение или отсутствие файла — ошибка. `pnpm --filter @shelkovo/ical test` запускает ту же строгую проверку.

Для намеренного обновления:

```bash
pnpm --filter @shelkovo/ical exec vitest run src/index.test.ts -u
```

После обновления просмотрите diff и повторите запуск с `--update=none`. Проверки CRLF, UTF-8-переносов и encoding выполняются отдельно от снапшотов. `.gitattributes` в папке эталонов сохраняет их CRLF при checkout.

## Ручной импорт в Apple Calendar

Импортируйте **эти же файлы** в отдельный тестовый календарь до merge реализации. При повторной проверке очистите тестовый календарь: UID файлов стабильны, а поведение повторного импорта зависит от клиента.

Время ниже указано для Москвы (UTC+3). В другом часовом поясе Calendar покажет соответствующее местное время. У каждого файла свой UID; названия и ссылка на новость демонстрационные.

- [with-place.ics](src/fixtures/with-place.ics): 19 сентября 2026 года, 12:00–13:30, длительность 1 час 30 минут. Заголовок «Встреча соседей», описание «Обсудим планы на осень.» и после пустой строки «Встречаемся у входа.». Место — «Место встречи, улица Центральная, 46–48», координаты `55.06505,37.720861`.
- [without-place.ics](src/fixtures/without-place.ics): те же дата, время и длительность. Описание «Обсудим планы на осень.». Поле места пустое, карта не появляется.
- [place-without-address.ics](src/fixtures/place-without-address.ics): те же дата, время, длительность и короткое описание. Место — «Место встречи» с теми же координатами, без дописанного адреса.
- [escaped-text.ics](src/fixtures/escaped-text.ics): с 23:30 19 сентября до 04:15 20 сентября 2026 года, длительность 4 часа 45 минут. Длинные кириллица и emoji 🌳 читаются без потерь. В заголовке и описании сохраняются запятая, точка с запятой и обратная косая черта; в описании видны отдельные строки «Вторая строка», «Третья строка», «Конец.». Название места начинается с `Клуб "Лес" ^n \ вход`, затем идут строки «этаж», «зал», «сад; север, юг». Кавычки, буквальное `^n` и обратная косая черта не превращаются в служебные escape-последовательности.

Во всех записях проверьте ссылку `https://example.com/news/calendar/`; в последнем файле она содержит `?a=1,2;b=3` без добавленных обратных косых черт. В трёх файлах с местом проверьте его распознавание Calendar и положение на карте по координатам. Автоматические тесты подтверждают поля ICS; отображение места в Apple Calendar проверяет владелец вручную.
