# ADR-033: Сравнение тарифов как часть единого сайта

## Статус

Принят

## Дата

2026-08-30

## Контекст

Сравнение тарифов возникло как отдельное приложение, затем вошло в `kpshelkovo.online`. Отдельные названия и документация продолжали создавать впечатление самостоятельного продукта, хотя раздел уже использовал общий build, layout, навигацию и deploy.

Данные поселков, расчёты и интерактивные представления при этом образуют собственный связный домен. Его полезно отделять от общих модулей сайта.

## Решение

Сравнение остаётся частью единого приложения с собственной доменной границей. Общие layout, навигация и публикация не дублируются отдельными app-level конфигурациями или deploy-потоком. Внутренний namespace `compare` отделяет специализированные данные и расчёты, не создавая самостоятельный публичный продукт.

Публичные названия берутся из [глоссария](/GLOSSARY.md#разделы-сайта), размещение кода — из [инструкций приложения](/apps/www/AGENTS.md#правила). Устойчивый префикс `/815/compare/` и его сохранение в HTML, Markdown и JSON определяет [site-navigation](/openspec/specs/site-navigation/spec.md).

Промежуточная крошка «Тариф 815» не нужна, пока `/815/` не имеет собственной страницы: принадлежность уже видна из навигации и URL, а ссылка на несуществующую страницу создала бы ложный уровень иерархии.

## Рассмотренные альтернативы

- **Вернуть отдельное приложение:** снова дублирует инфраструктуру и усиливает расхождение пользовательских и машинных представлений.
- **Растворить сравнение в общих папках:** смешивает специализированные расчёты и данные с общими модулями; доменная граница остаётся полезной внутри одного приложения.
- **Перенести из `/815/`:** не даёт достаточной пользы для миграции уже публичных ссылок и машинных представлений.

## Последствия

У сравнения общие бренд, оформление и публикация сайта при самостоятельных доменных модулях и тестах. Изменения внутренней структуры не требуют изменения публичного адреса. Отдельные конфигурации приложения, сборка и deploy для этого домена противоречили бы выбранному объединению.
