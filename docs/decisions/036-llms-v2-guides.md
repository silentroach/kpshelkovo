# ADR-036: Короткие путеводители llms.txt v2

## Статус

Принят

## Дата

2026-09-12

## Контекст

Lighthouse не распознавал навигацию в llms: AST сериализовал URL без названий как автоссылки. Двенадцать коротких и полных файлов дублировали инструкции, содержали изменчивые счетчики и не всегда объясняли полноту источника. Исправление одной ссылки снимало ошибку аудита, но не помогало агенту выбрать данные и правильно их понять.

## Решение

По [задаче #712](https://github.com/silentroach/kpshelkovo/issues/712) публикуем шесть самостоятельных путеводителей: корневой и разделовые для новостей, статуса, людей, регламента и сравнения. Принимаем структуру [llmstxt.org v2](https://llmstxt.org/): H1, короткий blockquote, необходимые вводные пояснения, затем H2 со списками именованных абсолютных ссылок.

Все шесть `llms-full.txt` удаляем без редиректов. Это решение проекта, а не требование спецификации. Пояснения сохраняем в существующих публичных инструкциях и документах по данным. `full.md`, `full/*.md` и JSON полного регламента остаются самостоятельными материалами.

Путеводители объясняют назначение и полноту ресурсов. Для отдельных материалов рекомендуем Markdown, для массовой обработки — полные JSON-ленты, для интерфейса — HTML. Календарные метаданные новости и ICS-ссылки читаются из JSON даже для одной статьи. Корень охватывает все содержательные разделы через их путеводители или Markdown-индексы.

Общий HTML-layout выбирает наиболее конкретный llms по путям из реестра публичных ресурсов. Для остальных разделов действует корневой fallback. Nginx публикует ту же связь `describedby` в HTTP `Link` для HTML, прямого Markdown и ответа через `Accept: text/markdown`. Реестр остается описательным: генерацию nginx не добавляем.

## Проверки

- Проверяем итоговую сериализацию всех генераторов, включая оставшиеся автоссылки рядом с корректными ссылками; используем Zod без полных текстовых snapshots.
- Проверяем покрытие разделов, каталоги и существование целевых ресурсов в сборке.
- Проверяем реальные HTTP-ответы nginx и служебные ссылки HTML; заголовки prerendered endpoint сами по себе не подтверждают заголовки сервера.
- Формат дополняем заданиями для агентов с чистым контекстом: стартуют только с вопросом и llms, фиксируют переходы и ответ со сверкой по источникам.

## Последствия

Это уточнение состава публичных ресурсов в ADR-008 и ADR-011; AST API и реестр остаются в силе. Full-файлы больше не входят в публикационный контракт. Путеводители не загружают доменные наборы ради счетчиков и примеров карточек.

PR готов к слиянию после проверки сборки. Задачу закрываем после деплоя, проверки production и повторного аудита; до этого PR использует `Refs #712`.
