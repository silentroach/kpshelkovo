# ADR-026: IndexNow после статического deploy

## Статус

Заменён [ADR-027](/docs/decisions/027-indexnow-new-pages-only.md).

## Дата

2026-08-16

## Причина замены

Первоначальное решение отправляло добавленные, изменённые и удалённые HTML-маршруты по checksum-diff. Изменение общего клиентского бандла меняло ссылки почти во всех HTML и создавало массовую отправку без содержательного обновления страниц. ADR-027 ограничил уведомления новыми индексируемыми страницами.

Действующий порядок публикации ключа, отправки после deploy и восстановления pending сохранён в [deploy-runbook](/README.md#indexnow): для эксплуатации историческое решение не требуется.
