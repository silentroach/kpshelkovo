# ADR-037: Печать справки и новостей через CSS

## Статус

Принят

## Дата

2026-09-13

## Контекст

Жители распечатывают справку и новости или сохраняют их в PDF. Экранные меню, оглавление и кадрирование фотографий мешали чтению. В [#723](https://github.com/silentroach/kpshelkovo/issues/723) выбран печатный вид существующей страницы, охватывающий `/kb/` и `/news/` вместе со списками, архивами и страницами-разделами.

## Решение

Использовать штатную печать браузера и CSS поверх существующего DOM. Содержимое поступает из той же страницы; сохранение PDF выполняют браузер и ОС. Отдельный генератор, серверный маршрут или редакционная копия материала создали бы второй рендер и потребовали бы синхронной поддержки.

Иллюстрации печатаемых материалов загружаются при открытии страницы независимо от прокрутки. На проверке непрокрученного материала Chrome сохранил только две из четырёх схем при lazy-загрузке. Eager-загрузка устранила эту зависимость ценой загрузки всех иллюстраций при открытии. Асинхронный `beforeprint` не выбран: браузер не обязан ждать его завершения, а CSS не загружает отсутствующие изображения.

Print-оформление ограничено справкой и новостями. Другие разделы имеют собственную геометрию и задачи; общий сброс для всего сайта затронул бы их без проверки. Критерий печати — полнота и читаемость, поскольку формат бумаги, масштаб и браузер влияют на разбиение страниц.

## Владельцы требований и оформления

- Содержимое, ссылки, скрытие интерфейса и читаемое разбиение — [content-print](/openspec/changes/extract-content-print-contract/specs/content-print/spec.md).
- Печать загруженных редакционных карт, включая сцену и выбранный кадр, — [site-maps](/openspec/specs/site-maps/spec.md#requirement-markdown-карта-остаётся-содержимым-печатной-страницы). Отдельного ожидания внешних ресурсов перед системным диалогом не вводится.
- Владение CSS — [ADR-034](/docs/decisions/034-native-css-architecture.md); визуальные параметры — [дизайн-гайд](/docs/design/design-code-shelkovo.md#печатное-представление); текущие селекторы и переопределения — [print.css](/apps/www/src/styles/print.css).

## История приёмки

[PR #728](https://github.com/silentroach/kpshelkovo/pull/728) содержит результаты Chrome и оставшиеся непроверенными сценарии Safari на компьютере и системного сохранения на iPhone/Android. Они не считаются пройденными при переносе документации.

Для редакционных карт есть [протокол раннего пробника](/docs/research/editorial-maps/print-acceptance.md). Владелец [снял браузерную и системную проверку печати с критериев готовности `editorial-maps`](https://github.com/silentroach/kpshelkovo/issues/819#issuecomment-5798818614), сохранив само поведение в контракте. Исторические границы проверки не создают новую браузерную матрицу для документационного изменения.
