# ADR-032: Предзагрузка HTML по нажатию

## Статус

Принят

## Дата

2026-08-28

## Контекст

ADR-002 выбрал `hover` как глобальную стратегию предзагрузки внутренних HTML-страниц. На страницах с большим количеством ссылок курсор может задерживаться над ссылками без намерения перейти по ним. В результате сайт начинает фоновые запросы, которые не помогают навигации и конкурируют с более важными ресурсами.

Нужно сократить ошибочные предзагрузки, сохранив ранний старт запроса при фактическом нажатии мышью или касании. Действующий контракт для не-HTML-ресурсов должен остаться без изменений.

## Решение

Сохранить глобальный `prefetchAll: true`, но переключить стратегию по умолчанию на `tap`:

```ts
prefetch: {
  prefetchAll: true,
  defaultStrategy: 'tap',
}
```

Astro начинает предзагрузку непосредственно перед переходом по нажатию или касанию. Простое наведение и фокус больше не запускают запрос.

Отдельные ссылки по-прежнему могут переопределять стратегию через `data-astro-prefetch`. Ссылки на PDF, Markdown, JSON, XML, календари, vCard и другие не-HTML-ресурсы должны использовать `data-astro-prefetch="false"` или общий `ResourceLink` согласно ADR-002.

Это решение заменяет только выбор глобальной стратегии из ADR-002. Остальные решения ADR-002 о `<ClientRouter />`, `prefetchAll`, кешировании HTML и защите не-HTML-ресурсов остаются в силе.

## Рассмотренные альтернативы

### Оставить `hover`

Плюсы:

- HTML может загрузиться раньше клика на компьютере.

Минусы:

- случайное движение курсора создает ненужные фоновые запросы;
- на страницах со многими ссылками эти запросы расходуют трафик и конкурируют с текущей страницей.

Отклонено: более ранний прогрев не оправдывает ошибочные запросы без подтвержденного намерения перейти.

### Отключить глобальную предзагрузку

Плюсы:

- нет фоновых запросов до навигации.

Минусы:

- запрос начинается только после обычного перехода;
- каждую ссылку для предзагрузки пришлось бы размечать отдельно.

Отклонено: `tap` дает более точный сигнал намерения и при этом сохраняет ранний старт перехода.

## Последствия

- Наведение и фокус на ссылке не расходуют трафик на следующую страницу.
- Нажатие мышью и касание запускают предзагрузку непосредственно перед переходом.
- Переход на компьютере может начать загрузку позже, чем при `hover`; это осознанный обмен небольшой части запаса времени на сокращение лишних запросов.
- Защита ссылок на не-HTML-ресурсы остается обязательной и проверяется существующим аудитом.

- Настройка `prefetch.defaultStrategy`: https://docs.astro.build/en/reference/configuration-reference/#prefetchdefaultstrategy
