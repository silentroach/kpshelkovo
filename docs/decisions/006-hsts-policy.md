# ADR-006: HSTS без `includeSubDomains` и `preload`

## Статус

Принят

## Дата

2026-05-15

## Контекст

Lighthouse предлагает распространить HSTS на поддомены и включить preload. Это обязательство для всего дерева домена: поддомен без корректного HTTPS станет недоступен, а удаление из preload распространяется по браузерам медленно. Набор хостов в репозитории не заменяет авторитетный инвентарь DNS и будущего использования поддоменов.

## Решение

Сохраняем host-only HSTS без `includeSubDomains` и `preload`. Основной HTTPS-хост отдаёт его через [security.conf](/ops/nginx/security.conf); HTTPS-редирект `www` имеет собственный HSTS в [site-конфиге](/ops/nginx/kpshelkovo-online.conf), чтобы прямой заход запоминал защиту этого хоста до перенаправления. Точные значения принадлежат конфигурации.

Предупреждение Lighthouse принимается: расширять область принудительного HTTPS ради балла несоразмерно риску. Перед `includeSubDomains` нужны полный инвентарь, проверка HTTPS на всех поддоменах и поэтапное включение с короткого срока. Preload требует отдельного решения с учётом долгосрочного обязательства и медленного отката.
