# ADR-007: COOP без COEP для изоляции `opener`-связей

## Статус

Принят

## Дата

2026-05-15

## Контекст

Сайту нужна защита от межсайтовых `window.opener`-связей, но нет сценария внешней авторизации или платежей, которому такой обмен между окнами необходим. Карты через JS API и Метрика — принятые сторонние интеграции; их загрузка сама по себе не требует сохранять `opener`.

## Решение

Основной HTTPS-хост отдаёт `Cross-Origin-Opener-Policy: same-origin` через [security.conf](/ops/nginx/security.conf). Отдельный COOP на доменах-редиректах не нужен: они не показывают документ, а итоговая страница получает политику основного хоста.

COEP не включаем. Возможности, требующие `crossOriginIsolated`, сайту не нужны, а COEP потребовал бы проверить CORP/CORS всех сторонних ресурсов и мог бы нарушить работу интеграций. COOP самостоятельно решает задачу изоляции `opener`, но не даёт полноценный `crossOriginIsolated`.

`same-origin-allow-popups` ослабил бы защиту ради отсутствующего сценария. Если появится интеграция с OAuth, платежами или обменом через `window.opener`, сначала проверяем её COOP-совместимость. Включение COEP требует отдельного решения и проверки сторонних ресурсов в браузерах.
