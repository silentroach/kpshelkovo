# Задача 07: Разметить страницы регламента

## Цель

Индексировать полезные объяснения и таблицы регламента, не превращая calculator UI в поисковый текст.

## Объем работы

- Использовать manual scope для основной страницы регламента.
- Отметить отдельными `data-pagefind-body` header, объяснения, смысловые таблицы и другие самостоятельные reference sections.
- Исключить inputs, controls, технические подсказки и повторяющиеся calculator labels.
- Индексировать самостоятельные страницы услуг и общего имущества только в части уникального содержания и таблиц.
- Сохранить sources и единицы измерения, если без них найденный факт становится неоднозначным.

## Критерии приемки

- Запрос по услуге, имуществу или формулировке регламента возвращает правильную canonical page.
- Excerpt содержит понятный факт с контекстом, а не текст элементов управления.
- Калькулятор продолжает работать независимо от поисковой разметки.

## Проверка

- Запустить production build и существующие проверки регламента.
- Вручную проверить три поисковых запроса по разным смысловым секциям.
- Не добавлять тесты на точный HTML таблиц или `data-pagefind-*` каждого элемента.
