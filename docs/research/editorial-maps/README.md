# Контрольные экспорты Конструктора Яндекса

Исходные данные для вопроса [«Определить поддерживаемый экспорт Конструктора Яндекса»](https://github.com/silentroach/kpshelkovo/issues/815) в карте [«Редакционные карты в Markdown и общий формат геоданных»](https://github.com/silentroach/kpshelkovo/issues/812). История решения хранится в обсуждении вопроса; актуальный план — в [OpenSpec change `editorial-maps`](../../../openspec/changes/editorial-maps/proposal.md). Эти файлы фиксируют формат контрольных экспортов для проверки реализации; их хранение здесь само по себе не публикует новую редакционную схему на сайте.

## Происхождение

Оба файла экспортировал из Конструктора и передал владелец проекта 23 сентября 2026 года. Штатный форматтер проекта расставил отступы в JSON; поля, значения, порядок объектов, исходные тексты и параметры оформления сохранены. Контрольные суммы ниже относятся к полученным однострочным исходникам до форматирования.

- [`yandex-detour.geojson`](yandex-detour.geojson) — получен как `real.geojson`.
  - [Схема из Конструктора в Яндекс Картах](https://yandex.ru/maps/?um=constructor%3A868dc810f703c33e9d996846f6e6ec6a103fff5a3c76fa44c6a05325a9666e0d&source=constructorLink).
  - Три `Point` и один `LineString`: подписи точек, пояснение ворот, красная линия объезда.
  - В `metadata` есть название, описание и инструмент создания. У линии «Путь» находится в `description`; отдельного `iconCaption` у неё нет.
  - SHA-256 исходника: `3a1b1ab749472625e61563c369221a9e2f1380452a28e566cc38a62d8a0d8eb4`.
- [`yandex-polygons.geojson`](yandex-polygons.geojson) — получен как `real-test-poly.geojson`.
  - Два `Polygon`: первый с одним внешним кольцом, второй с внешним и внутренним кольцами. Это контрольный пример области с вырезом.
  - У обоих есть пояснение, жёлтая заливка с прозрачностью `0.6` и красная обводка с прозрачностью `0.9`.
  - Отдельную ссылку на эту карту владелец не передавал.
  - SHA-256 исходника: `4d32be637282dacd808e8580a02aee67031f33023d42ca20683a159f2fe892d5`.

## Проверенные особенности

- Оба файла — `FeatureCollection` с числовыми ID, включая `0`; `stroke-width` записан строкой `"5"`.
- Координаты записаны в порядке `[долгота, широта]`. Для схемы объезда это соответствует расположению Семеновского и Шелково.
- На этапе исследования геометрия обеих областей прошла `RawPolygonGeometrySchema`: проверены координатные диапазоны, замыкание колец, число различных вершин и ненулевая расчётная площадь. Эта ранняя проверка не оценивала импорт полного экспорта или его визуальное отображение.
- В обоих экспортах пояснения содержат обычный текст. Позднейшие решения карты закрепили сохранение описаний без показа и без разбора Markdown; первоначальный план поддержки Markdown в пояснениях заменён. Производный пример с разметкой нужен для проверки сохранения строк и безопасного отображения, а не поддержки Markdown.
- Ранняя браузерная проверка внешней ссылки на объезд вернула страницу `limited`; она не включала сравнение с картой внутри сайта или проверку перехода в мобильное приложение.
- Для составной области дополнительным существующим примером служат [Охотничьи пруды](../../../apps/www/src/data/places/hunting-ponds.geojson): `MultiPolygon` из двух полигонов. Это проектные геоданные места, а не свежий экспорт Конструктора.
